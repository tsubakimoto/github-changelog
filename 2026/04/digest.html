重要アップデート（ピックアップ）

  • Upcoming deprecation of Claude Sonnet 4 in GitHub Copilot - モデル非推奨期限が明示され、運用中のモデル設定変更を早期に進める必要があります。
  • GPT-5.1 Codex, GPT-5.1-Codex-Max, and GPT-5.1-Codex-Mini deprecated - Codex系モデルの切替対応が必要で、CLI/IDEの利用ポリシーに直接影響します。
  • Codespaces is now generally available for GitHub Enterprise with data residency - データレジデンシー環境でCodespacesがGA化し、規制対応下でも導入しやすくなりました。
  • Copilot SDK in public preview - Copilot拡張の実装面が広がる更新で、独自連携を進めるチームの選択肢が増えます。
  • Copilot data residency in US + EU and FedRAMP compliance now available - コンプライアンス要件の厳しい組織で、Copilot採用を進めやすくなる重要な公開です。
  • OIDC support for Dependabot and code scanning - セキュリティ連携の認証設計を改善でき、トークン管理の負担軽減につながります。
  • GPT-5.5 is generally available for GitHub Copilot - CopilotでGAモデルが追加され、本番利用でのモデル選択が強化されました。
  • GitHub Copilot code review will start consuming GitHub Actions minutes on June 1, 2026 - 利用コストに直結する課金仕様変更で、Actions予算見積りの更新が必要です。
