## Self-hosted runner version enforcement date has moved

**URL:** https://github.blog/changelog/2026-09-28-self-hosted-runner-version-enforcement-date-has-moved

### 要約
GitHub Enterprise Cloud における GitHub Actions セルフホストランナーの最低バージョン要件の完全適用開始日が、2026 年 9 月 29 日に変更されました。要件自体は変わらず、バージョン 2.329.0 未満のランナーは登録・再登録できなくなり、ジョブ実行に必要な最低バージョンを満たさない既存ランナーもジョブを実行できなくなります。

### ユーザーにとって良いこと
適用日が明確になったことで、ワークフロー停止を避けるためのアップグレード期限を把握しやすくなります。新しいランナーバージョン非推奨 REST API を使えば、ランナーフリートの期限を確認し、期限が近い環境への自動アラートも構築できます。

### アクションプラン
- GitHub Enterprise Cloud で使用しているセルフホストランナーを確認し、バージョン 2.329.0 以上へアップグレードする。特にジョブ実行の最低バージョン要件も満たしていることを確認する。
- ランナーの登録日・実行停止予定日を新しい REST API で定期的に取得し、期限が近いランナーを自動通知する仕組みを構築する。
- ⚠️ 完全適用は 2026 年 9 月 29 日から。未対応のランナーはワークフローに影響する可能性があるため、対象フリートを直ちに確認する。
- この変更は GitHub Enterprise Cloud が対象。GitHub Enterprise Server には影響せず、GitHub Enterprise Cloud with Data Residency では 2026 年 7 月 31 日から適用済み。

## Claude Sonnet 5.5 in GitHub Copilot

**URL:** https://github.blog/changelog/2026-09-28-claude-sonnet-5-5-in-github-copilot

### 要約
Anthropic の Claude Sonnet 5.5 が GitHub Copilot で一般提供されました。日常的な機能開発やバグ修正など、範囲が明確な作業向けに設計され、Claude Sonnet 5 と同等のコーディング性能を、より少ないステップ・トークン・ツール呼び出しで実現し、処理時間も短縮されています。

### ユーザーにとって良いこと
対象プランのユーザーは、効率と速度に優れたモデルを使って、実装や修正作業をより迅速に進められます。モデルピッカーから複数の Copilot 対応環境で選択でき、使用量ベースの課金ではプロバイダーの定価に基づいて利用料金を把握できます。

### アクションプラン
- Copilot Pro、Pro+、Max、Business、Enterprise のユーザーは、モデルピッカーで Claude Sonnet 5.5 を選択し、範囲の明確な実装・バグ修正で既存モデルと比較する。
- Copilot Business または Enterprise の管理者は、Copilot 設定のモデルポリシーで利用可否を確認・管理する。デフォルトのモデル有効化が有効なら、新モデルは自動的に有効になる。
- 使用量ベースの課金が適用されるため、Models and pricing の情報を確認し、チームの利用量と予算への影響を監視する。
- VS Code、Visual Studio、Copilot CLI、Copilot coding agent、Copilot app、GitHub.com、GitHub Mobile、JetBrains IDEs、Xcode、Eclipse などで段階的に展開されるため、表示されない場合は後で再確認する。
