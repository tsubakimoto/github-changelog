## Add VS Code Agents to Copilot usage metrics

**URL:** https://github.blog/changelog/2026-09-11-add-vs-code-agents-to-copilot-usage-metrics

### 要約
Copilot usage metrics の集計レポートに、VS Code の専用 Agents ウィンドウでの利用状況を示す新しい指標が追加されました。enterprise / organization の 1日・28日集計に加え、ユーザー単位のレポートでも VS Code Agents の利用有無やセッション数、メッセージ数を確認できます。

### ユーザーにとって良いこと
VS Code Agents の導入率や定着度を、既存の Copilot 指標と並べて把握しやすくなります。組織やチームごとの利用実態が見えるため、機能の展開判断や教育施策の改善に役立ちます。

### アクションプラン
- enterprise owner / billing manager / organization owner は、Copilot usage metrics policy が有効か確認し、必要なら先に有効化してください。
- 既存の利用分析ダッシュボードに `daily_active_vscode_agent_users`、`totals_by_vscode_agent`、`used_vscode_agent` を追加してください。
- ⚠️ この指標は VS Code の専用 Agents ウィンドウのみを対象にするため、Editor の Agent Mode や一般的な利用集計と混同しないようにレポート名を分けてください。

## Auto-resolution and analysis updates in Copilot code review

**URL:** https://github.blog/changelog/2026-09-11-auto-resolution-and-analysis-updates-in-copilot-code-review

### 要約
Copilot code review が、対応済みのコメントを再レビュー時に自動で解決するようになりました。さらに、suggestion を適用したときのコミットメッセージがより内容に沿ったものになり、内部では shell tools の活用範囲拡大と Lite レベルの複数エージェント評価でレビュー品質が向上しています。

### ユーザーにとって良いこと
不要になったレビューコメントが自動で閉じるため、残すべき指摘だけに集中しやすくなります。suggestion 適用時のコミット操作も自然になり、レビューと修正の往復が少し速くなります。

### アクションプラン
- Copilot code review を使っているチームは、再レビュー後に未解決コメントだけが残る前提で運用フローを見直してください。
- suggestion を適用してコミットする手順を使うメンバーに、生成されるコミットメッセージが変わることを周知してください。
- Lite レベルの review を使う場合は、より詳細な検証が行われる前提で、既存のレビュー基準や期待値を更新してください。
