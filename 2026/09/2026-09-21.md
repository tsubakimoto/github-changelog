## GitHub Enterprise adds credential inventory exports

**URL:** https://github.blog/changelog/2026-09-21-github-enterprise-adds-credential-inventory-exports

### 要約
Enterprise 全体で利用できる認証情報の一覧を、CSV かページネーション付き REST API でエクスポートできるようになりました。SSH key、classic/fine-grained PAT、OAuth App token、GitHub App の各種トークンまで含めて、所有者、権限、作成/期限、最終利用日、対象 org/repo などのメタデータを確認できます。

### ユーザーにとって良いこと
インシデント時に、どの認証情報が影響を受けうるかを短時間で洗い出せます。権限過多や未使用の credential を可視化して、棚卸しやリスク低減の運用にも使えます。

### アクションプラン
- Enterprise owner は `Settings -> Authentication Security -> Credentials` から CSV を出力し、または新しい REST API を使って定期棚卸しを自動化してください。
- セキュリティチームは、所有者・スコープ・最終利用日・期限切れを基準に、不要または高リスクな credential を優先的に見直してください。
- ⚠️ インシデント対応手順に、この export を使った影響範囲確認と監査ログ突合の手順を追加してください。Enterprise Cloud で利用可能で、Enterprise Server は今後のリリースで対応予定です。

## Grok 4.7 is now available in GitHub Copilot

**URL:** https://github.blog/changelog/2026-09-21-grok-4-7-is-now-available-in-github-copilot

### 要約
GitHub Copilot で Grok 4.7 が順次利用可能になりました。エージェント的なコーディングや複数ステップの推論に向いたモデルで、使用量ベース課金では provider の定価が適用されます。

### ユーザーにとって良いこと
複雑な実装支援や反復的なタスクで、より強い推論モデルを選べるようになります。対応 SKU も広く、VS Code や Copilot CLI など既存の利用導線から試しやすいのが利点です。

### アクションプラン
- Copilot Enterprise / Business の管理者は、Copilot 設定の model policy で Grok 4.7 の許可状態を確認してください。
- 利用者は、モデルピッカーで Grok 4.7 が表示されるか確認し、必要なら VS Code、Copilot CLI、cloud agent などで試用してください。
- 使用量ベース課金を使っている場合は、provider list pricing 前提でコスト影響を確認し、チームへ周知してください。
- ⚠️ ロールアウトは段階的です。まだ表示されない場合は、短時間待って再確認してください。
