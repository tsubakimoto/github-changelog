## GitHub Copilot weekly releases — August 31

**URL:** https://github.blog/changelog/2026-09-04-github-copilot-weekly-releases-august-31

### 要約
GitHub Copilot の今週の更新をまとめた案内です。モデル選択の拡充やコンテンツ保護の強化に加え、VS Code では agent session の管理や pull request をマージ可能な状態に近づけるための機能が追加されています。JetBrains、Copilot app、Copilot CLI など複数の利用面にも更新が入っています。

### ユーザーにとって良いこと
Copilot を使う環境ごとの機能差が縮まり、日常の開発フローでより一貫した体験を得やすくなります。セッション管理やマージ支援が強化されたことで、長い作業の整理や PR 対応の手戻りも減らしやすくなります。

### アクションプラン
- Copilot のモデル選択で利用可能な新しいモデルを確認し、用途ごとの既定モデルを見直してください。
- VS Code を使っている場合は、Agent Merge と chat session 階層表示を試し、チームの作業整理に合うか確認してください。
- Copilot app と Copilot CLI で content exclusions が期待どおりに効いているかを確認し、必要なら組織の利用ルールを更新してください。

## GPT-6 Astra is generally available in GitHub Copilot

**URL:** https://github.blog/changelog/2026-09-04-gpt-6-astra-is-generally-available-in-github-copilot

### 要約
OpenAI の GPT-6 Astra が GitHub Copilot で一般提供になりました。長い作業の計画と検証を繰り返す agentic なコーディングに向いたモデルとして案内されており、usage-based billing の対象です。VS Code、Visual Studio、Copilot CLI、coding agent、Copilot app、github.com、モバイル、JetBrains、Xcode、Eclipse など幅広い環境で選択できます。

### ユーザーにとって良いこと
長いタスクや複数段階の実装で、計画・診断・検証をまとめて任せやすくなります。利用できる開発環境が広いため、普段のツールを変えずに新しいモデルを評価しやすい点も利点です。

### アクションプラン
- Copilot のモデルピッカーで GPT-6 Astra を試し、既存モデルとの速度と品質を比較してください。
- Copilot Business / Enterprise の管理者は、モデルポリシーでこのモデルを有効化し、必要な利用者に届くようにしてください。
- ⚠️ usage-based billing の対象なので、自動化ジョブや長時間の agent 利用では請求影響を事前に確認してください。

## New API endpoint provides privacy-safe star history data

**URL:** https://github.blog/changelog/2026-09-04-new-api-endpoint-provides-privacy-safe-star-history-data

### 要約
リポジトリの star 推移を追跡できる新しい REST API エンドポイントが追加されました。stargazer の個別情報を公開せずに、時系列の star 数を取得できます。以前はプライバシー保護のために制限された stargazer listing endpoint の代わりとして使える設計です。

### ユーザーにとって良いこと
個人の stargazer 情報を扱わずに人気の推移を把握できるため、プライバシーに配慮したまま分析や可視化を続けやすくなります。既存の監視やダッシュボードも、より安全な取得方法に寄せられます。

### アクションプラン
- star 増加を追跡しているツールやダッシュボードを、新しい star history API に置き換えてください。
- もし stargazer listing に依存した実装があるなら、個人識別情報を前提にした処理を削除してください。
- API ドキュメントでレスポンス形式と制限事項を確認し、取得頻度や保存期間の設計を調整してください。
