重要アップデート（ピックアップ）

  • Gemini 3 Pro deprecated - 既存モデルの非推奨で、チームのモデル利用設定とドキュメント更新が必要です。
  • Deprecating the cost center integration on the enterprise People page - Enterprise運用の管理画面連携に影響するため、運用フローの見直しが必要です。
  • GPT-5.4 is generally available in GitHub Copilot - Copilotの主要モデルがGA化し、本番利用の標準候補として扱いやすくなりました。
  • REST API version 2026-03-10 is now available - APIバージョン更新で互換性確認とクライアント実装の追随が必要です。
  • Issue fields: Structured issue metadata is in public preview - Issue管理の構造化が進み、プロジェクト運用ルールの拡張余地が広がります。
  • Custom images for GitHub-hosted runners are now generally available - Actions実行基盤の標準化と高速化に効く、運用インパクトの大きいGAです。
  • Credential revocation API now supports GitHub OAuth and GitHub app credentials - 認証情報失効APIの対応範囲が拡大し、インシデント対応を自動化しやすくなります。
  • EU data residency region expanding to include EFTA countries - データレジデンシー要件下での利用可能地域が増え、導入可能な組織範囲が広がります。
