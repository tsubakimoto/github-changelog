## New controls and chat improvements in Copilot for JetBrains

**URL:** https://github.blog/changelog/2026-10-10-new-controls-and-chat-improvements-in-copilot-for-jetbrains

### 要約
GitHub Copilot for JetBrains で、Enterprise 管理者が新しい会話のデフォルトにする Copilot エージェントモデルを管理設定から選択できるようになりました。診断メニューからインラインチャットで修正を依頼する機能や、Copilot と Claude の MCP サーバー自動起動を無効にする設定も追加され、チャットのターン間移動、メッセージのコピー・編集、アカウント切り替えなどの操作性も改善されています。また、JetBrains IDE 2025.1 のサポートは終了し、プラグインの利用には 2025.2 以降が必要です。

### ユーザーにとって良いこと
組織は新しい会話で使うモデルを統一しつつ、利用者にはモデル選択の余地を残せます。診断から修正案を得る手順が短くなり、MCP サーバーの起動タイミングも制御できるため、日々の作業効率とツール利用の管理性が向上します。チャットやアカウント操作も見つけやすくなります。

### アクションプラン
- Enterprise 管理者は、組織の利用方針に合わせて新しい会話のデフォルトモデルを管理設定で選択してください。設定後も利用者はモデルピッカーからモデルを選べます。
- MCP サーバーを必要なときだけ起動したい場合は、Copilot と Claude の自動起動を無効にする新しい設定を確認してください。
- JetBrains IDE 2025.1 を使用している場合は、Copilot プラグインを継続利用するため IDE を 2025.2 以降に更新してください。2025.1 はサポート対象外です。
- 最新の Copilot プラグインに更新し、診断メニューの **Fix**、ターン間移動、メッセージのコピー・編集、アカウント切り替えを試してください。
