## Webhook IP ranges added to the Meta API

**URL:** https://github.blog/changelog/2026-10-29-webhook-ip-ranges-added-to-the-meta-api

### 要約
GitHub.com の webhook 配信に使用される IP 範囲が追加され、Meta API の `hooks` フィールドから取得できるようになりました。追加された CIDR は `9.234.98.160/28`、`9.234.98.176/28`、`9.234.106.48/28` です。すべてのプラン（GitHub Enterprise Cloud を含む）が対象です。

### ユーザーにとって良いこと
Meta API で最新の webhook IP 範囲を管理でき、送信元 IP の変更による webhook 配信の拒否を防ぎやすくなります。API を使わず静的な許可リストを管理している場合も、追加範囲を登録すれば配信を継続できます。

### アクションプラン
- webhook 配信元 IP の静的な許可リストを管理している場合は、`9.234.98.160/28`、`9.234.98.176/28`、`9.234.106.48/28` を既存の範囲に追加してください。
- Meta API から webhook IP 範囲を定期取得して許可リストを更新している場合、今回の追加に伴う変更は不要です。
- 設定変更後、受信側ネットワークで GitHub.com からの webhook 配信が許可されることを確認してください。
