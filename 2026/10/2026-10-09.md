## GitHub Copilot weekly releases — October 5

**URL:** https://github.blog/changelog/2026-10-09-github-copilot-weekly-releases-october-5

### 要約
Copilot Pro、Pro+、Max、Business、Enterprise ユーザーが Claude Haiku 5.5 を利用できるようになり、Copilot CLI、Copilot アプリ、Agent Host を使う VS Code セッションでは、ファイル・ネットワーク・認証情報へのアクセスを制限するローカルサンドボックスが一般提供されました。また、Copilot アプリでライセンス用とリポジトリ用に別々の GitHub アカウントを設定でき、Copilot CLI の `/model` から実行中の Ollama のローカルモデルを選択できます。VS Code 1.141 ではエージェントセッションの並列表示と、チャットからの非アクティブな worktree の確認・削除が追加されました。

### ユーザーにとって良いこと
モデル選択や組織管理の Copilot ライセンスと個人アカウントのリポジトリ利用が柔軟になり、エージェントのアクセス範囲を制限して安全性を高められます。複数の作業結果を比較しやすくなり、不要な worktree を整理してディスク容量を確保できます。

### アクションプラン
- Copilot CLI、Copilot アプリ、または Agent Host を使う VS Code セッションでは、必要に応じてローカルサンドボックスのアクセス制限を設定してください。一般提供済みで、Copilot の追加料金はありません。
- 対象プランの利用者は Claude Haiku 5.5 をモデル選択肢として確認してください。追加設定は告知されていません。
- Copilot アプリで別のアカウントのリポジトリにアクセスしたい場合は、ライセンス用アカウントとリポジトリ用アカウントを個別に設定してください。
- Ollama を実行している Copilot CLI 利用者は `/model` で利用可能なローカルモデルを確認してください。VS Code 1.141 の利用者はエージェントセッション表示と worktree cleanup を利用できます。

## CodeQL 2.27.2 improves C++, Go, Rust, and JavaScript analysis

**URL:** https://github.blog/changelog/2026-10-09-codeql-2-27-2-improves-c-go-rust-and-javascript-analysis

### 要約
CodeQL 2.27.2 では C++ の `std::regex` における ECMAScript 文法の解析に対応し、C/C++、Go、Rust、JavaScript/TypeScript のデータフローやフレームワーク対応が改善されました。CLI のエラー報告や YAML データ拡張の検証も強化されています。一方、Go の制御フローグラフ（CFG）ライブラリが変更され、旧表現に依存するクエリには更新が必要な場合があります。

### ユーザーにとって良いこと
言語やライブラリに関するモデルの拡充と解析精度の向上により、コードスキャンでより適切に問題を検出できます。CLI の入力エラーも分かりやすくなり、不正な設定値による意図しない動作を防ぎやすくなります。

### アクションプラン
- GitHub.com のコードスキャン利用者には新しい CodeQL バージョンが自動展開されます。GHES 利用者は今後の GHES リリースへの収録を確認し、それ以前のバージョンでは必要に応じて CodeQL を手動でアップグレードしてください。
- Go の CFG 表現に依存するカスタム CodeQL クエリは、新しいノード・エッジや変更された型、非推奨 API（`IfStmt.getCond` から `IfStmt.getCondition`）を確認し、クエリを更新してください。
- コンパイル対象言語を macOS で解析する場合、autobuild/manual build mode は macOS 27 では利用できず、macOS 26 でも Xcode 27 では利用できません。これらのモードでは macOS 26 以下と Xcode 26 以下を使用してください。
- CodeQL CLI やクエリパックを管理するチームは、2.27.2 のリリースノートで各言語のモデル変更と CLI の変更点を確認してください。
