## Claude Haiku 5.5 in GitHub Copilot

**URL:** https://github.blog/changelog/2026-10-07-claude-haiku-5-5-in-github-copilot

### 要約
Anthropic の軽量モデル Claude Haiku 5.5 が GitHub Copilot で一般提供されました。高速な処理が求められるサブエージェント、簡単な編集、ターミナル作業などを想定しており、初期テストでは多くのコーディングタスクで Claude Sonnet 5 と同等の結果を、より少ないトークンとステップで実現しました。従量課金ではプロバイダーの公開価格が適用され、利用可能になる時期は段階的に展開されます。

### ユーザーにとって良いこと
対応する Copilot プランでは、日常的な作業に高速で効率のよいモデルを選べます。Visual Studio Code、Copilot CLI、JetBrains IDE など複数の環境からモデルを利用できます。

### アクションプラン
- Copilot Pro、Pro+、Max、Business、Enterprise の利用者は、モデルピッカーに Claude Haiku 5.5 が表示されたら作業内容に応じて選択してください。段階的な展開のため、表示されない場合は後日再確認してください。
- Copilot Business / Enterprise の管理者は、Copilot 設定のモデルポリシーを確認してください。グローバルな既定設定や個別ポリシーで無効にしていない限り、新しいモデルは既定で有効になります。
- 従量課金を利用する場合は、モデル選択前に GitHub Copilot のモデル別料金を確認してください。

## Purpose-built model for leaked secret detection

**URL:** https://github.blog/changelog/2026-10-07-purpose-built-model-for-leaked-secret-detection

### 要約
GitHub は、周辺コードの文脈を使って、一般的なトークン形式に当てはまらないパスワードなども検出する、秘密情報検出専用モデルを発表しました。既存の AI 検出によるパスワードアラートは GHSP / GHAS の利用者に対して新モデルへ自動移行され、追加料金はかかりません。一方、Push Protection と Copilot の `/security-review` に追加される AI 検査はオプトイン機能で、今後 AI Credits を消費します。

### ユーザーにとって良いこと
コードの文脈に基づく検出により、形式が一般的でない認証情報も見つけやすくなります。Push Protection では秘密情報が履歴に入る前に検出でき、Copilot のセキュリティレビューでは既存の LLM ベースのレビューに秘密情報検査が加わる予定です。

### アクションプラン
- GHSP / GHAS の管理者は、既存の AI 検出アラートが新モデルへ自動移行されることを確認してください。このアラート検査は追加料金なしで、GHES 3.23 では公開プレビューとして提供予定です。
- AI Push Protection はプライベートプレビューです。GitHub Enterprise Cloud または GitHub Team と GHSP / GHAS の対象環境では、利用資格、管理者ポリシー、AI Credits の料金を確認したうえで、必要な場合にのみ有効化してください。チェックはプッシュをブロックしない場合でもクレジットを消費し、使用量は原則リポジトリ所有組織に計上されます。
- `/security-review` への秘密情報検査追加は今後プライベートプレビューとして提供予定です。GHSP / GHAS ライセンスは不要ですが、オプトインが必要で、既存のレビュー使用量に加えて AI Credits を消費します。既定では無効であり、コマンドを実行するだけでは有効になりません。
- 新しいクレジット消費機能を有効化する前に、AI usage insights で対象 SKU の使用量を確認し、必要に応じて Secret Protection AI Credits の予算を設定してください。予算アラートだけでは利用は停止されないため、上限で停止したい場合は利用可能な環境で `Stop usage when budget limit is reached` も設定してください。

## Local sandboxing for GitHub Copilot now generally available

**URL:** https://github.blog/changelog/2026-10-07-local-sandboxing-for-github-copilot-now-generally-available

### 要約
GitHub Copilot CLI、Copilot アプリ、および Agent Host を使う VS Code セッションで、ローカルサンドボックスが一般提供されました。開発者や組織が定めたポリシーに基づいて、Copilot が実行するツールやコマンドのファイル、ネットワーク、認証情報などへのアクセスを制限します。Windows、macOS、Linux に対応し、Copilot の追加料金なしで利用できます。

### ユーザーにとって良いこと
エージェントによる作業を進めながら、ローカルファイルやネットワーク、Git / GitHub CLI の認証情報へのアクセス範囲を管理できます。組織管理設定でサンドボックスを必須にし、開発者がポリシーを弱められないようにすることもできます。

### アクションプラン
- Copilot CLI、Copilot アプリ、または Agent Host を使う VS Code セッションでエージェントを利用するチームは、サンドボックスのポリシーを設定し、読み書き可能なファイルやネットワークアクセスを必要最小限にしてください。
- 組織・エンタープライズ管理者は、必要に応じて管理設定でサンドボックスを必須化し、開発者が緩和できないポリシーを適用してください。ローカル MCP や言語サーバーなどのツールにも、対応範囲を確認して適用してください。
- モデルの実行とツールの隔離は別の設定です。利用モデルにかかわらず、ツール実行のアクセス境界をポリシーで確認してください。

## Discover local models in GitHub Copilot CLI

**URL:** https://github.blog/changelog/2026-10-07-discover-local-models-in-github-copilot-cli

### 要約
GitHub Copilot CLI 1.0.94-0 以降では、`/model` から稼働中のローカル Ollama インスタンスで利用できるモデルを検出し、設定済みモデルや Copilot のクラウドモデルと並べて選べるようになりました。検出されたモデルは自動追加されず、モデルを選んで確認した後、今のセッションで使用するか、切り替えずに追加するかを選択します。Ollama とモデルは事前にインストールが必要で、モデルはツール呼び出しとストリーミングに対応している必要があります。

### ユーザーにとって良いこと
CLI の作業を中断せずにローカルモデルを見つけて利用でき、プロバイダー接続の問題もモデルピッカーで確認できます。モデルの追加や切り替えに CLI の再起動は不要です。

### アクションプラン
- ローカルモデルを使う場合は Copilot CLI 1.0.94-0 以降を利用し、Ollama とツール呼び出し・ストリーミング対応モデルを事前に起動してください。`/model` で検出したモデルのプロバイダーとエンドポイントを確認してから追加してください。
- この機能は Ollama やモデルをインストール・ダウンロードしません。利用前に必要なランタイムとモデルを別途用意してください。
- ローカルモデルの選択はオフラインモードの有効化や GitHub のテレメトリ無効化を意味しません。リモートプロバイダーはプロンプトやコードのコンテキストをネットワーク経由で受け取る可能性があります。オフライン実行が必要な場合は `COPILOT_OFFLINE=true` を明示し、接続先とデータ取り扱いを確認してください。
