## GitHub Copilot assisted permissions generally available

**URL:** https://github.blog/changelog/2026-10-26-github-copilot-assisted-permissions-generally-available

### 要約
GitHub Copilot CLI、GitHub Copilot app、Visual Studio Code で、Assisted permissions が一般提供されました。Copilot がコマンド実行、ファイルシステムへのアクセス、URL のオープンを要求すると、モデルが安全性を評価し、明らかに安全な要求は自動で進め、それ以外はユーザーの承認を求めます。

### ユーザーにとって良いこと
安全と判断された要求のたびに手動承認する手間を減らしながら、それ以外の操作については承認を維持できます。Enterprise 管理者は許可ポリシーを管理し、新しいセッションの既定モードも指定できます。

### アクションプラン
- Copilot CLI は `/permissions`、Copilot app はモードピッカーの **Tool permissions**、Visual Studio Code は権限ピッカーから **Assisted** を選択してください。この設定は各利用者・セッションで行います。
- Enterprise 管理者は Enterprise-managed settings で Assisted の利用可否と新規セッションの既定権限モードを設定してください。ポリシーで許可された別モードは開発者が選択でき、既定モードが利用不可または禁止されている場合は手動承認で開始します。
- モデルによる安全性評価は、すべての要求を自動許可するものではありません。承認が必要な要求は引き続き内容を確認して判断してください。Enterprise では **Allow All** を禁止しつつ **Assisted** を利用可能にする設定もできます。

## GPT-6.1 Terra in GitHub Copilot

**URL:** https://github.blog/changelog/2026-10-26-gpt-6-1-terra-in-github-copilot

### 要約
GPT-6.1 Terra が GitHub Copilot で一般提供されました。日常的なエージェント型コーディングやターミナル作業向けで、GPT-6.1 Sol より低コストとされ、Copilot Pro、Pro+、Max、Business、Enterprise で利用できます。

### ユーザーにとって良いこと
対応する Copilot クライアントで新しいモデルを選択でき、範囲の明確なコーディングやターミナル作業に活用できます。料金は使用量ベースで、プロバイダーの標準価格に基づいて請求されます。

### アクションプラン
- 利用可能になったら、VS Code、Visual Studio、Copilot CLI、cloud agent、Copilot app、github.com、GitHub Mobile、JetBrains IDEs、Xcode、Eclipse のモデルピッカーから GPT-6.1 Terra を選択してください。提供は段階的なロールアウトです。
- Copilot Business または Enterprise の管理者は、Copilot 設定のモデルポリシーで GPT-6.1 Terra へのアクセスを確認してください。新しいモデルは、グローバル既定が無効でなく、当該モデルが明示的に無効化されていなければ、既定で有効になります。
- 使用量ベースの料金を確認し、必要に応じてモデルの利用ポリシーや利用量の管理に反映してください。
