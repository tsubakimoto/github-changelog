## GitHub Copilot supports server-to-server authentication

**URL:** https://github.blog/changelog/2026-10-27-github-copilot-supports-server-to-server-authentication

### 要約
GitHub Copilot SDK を使うサービスやエージェントが、サインイン中のユーザーではなく、Organization にインストールされた GitHub App の ID で Copilot にリクエストできる機能がパブリックプレビューとして追加されました。GitHub App に読み取り専用の `Copilot Requests` Organization 権限を付与し、短期間有効なインストールアクセストークンを SDK に渡して利用します。

### ユーザーにとって良いこと
自動化サービスやエージェントが個人ユーザーの認証情報や利用枠に依存せず、Organization の主体として安定して動作できます。利用量は Organization に帰属し、Organization のモデルポリシー、予算、支出管理が適用されます。

### アクションプラン
- この機能を試す場合は、GitHub App に読み取り専用の `Copilot Requests` Organization 権限を付与して対象 Organization にインストールし、短期間有効なインストールアクセストークンを Copilot SDK に渡してください。パブリックプレビューのオプトイン機能です。
- Organization 管理者は Copilot にアクセスできるアプリを確認し、AI usage CSV レポートの `app_client_id` でアプリごとの利用量を把握してください。
- アプリのアクセスを停止する場合は、その GitHub App を一時停止またはアンインストールしてください。利用量は Organization に計上され、Organization のモデルポリシーと予算・支出管理の対象になります。
