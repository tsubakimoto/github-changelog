## Actions for ARM32 Linux & Windows retirement

**URL:** https://github.blog/changelog/2026-11-12-actions-for-arm32-linux-windows-retirement

### 要約
GitHub Actions の Windows および Linux ホステッドランナーで、ARM32 ジョブのサポートが 2026年12月8日に終了します。Node 20 のサポート終了に伴い、ARM32 に対応しない Node 24 へ移行するため、ネイティブの AArch32 ユーザー空間実行も対象となります。

### ユーザーにとって良いこと
この変更による直接的な機能追加はありませんが、Node 24 を含む今後のランタイムをサポートするための変更です。期限前に ARM32 を使うワークフローを特定すれば、ビルドやテストの停止を避けられます。

### アクションプラン
- 2026年12月8日までに、Windows / Linux ホステッドランナー上で ARM32 またはネイティブ AArch32 実行に依存する Actions ワークフローを洗い出してください。
- 対象ジョブをサポート対象のアーキテクチャへ移行するか、必要な実行環境を別途用意してください。期限以降、対象ホステッドランナーでの ARM32 実行は利用できません。

## Secret scanning detects Cloudflare service tokens

**URL:** https://github.blog/changelog/2026-11-12-secret-scanning-adds-a-detector-for-cloudflare

### 要約
Secret scanning が Cloudflare の `cloudflare_access_service_token` を新たに検出するようになりました。パブリックリポジトリで検出されたパートナーシークレットは連携プログラムを通じて発行元に自動報告され、ユーザーシークレットはパブリック・プライベート両方のリポジトリでアラートになります。

### ユーザーにとって良いこと
誤ってコミットされた Cloudflare Access service token を早期に発見し、漏えいによる不正利用のリスクを減らせます。検出されたシークレットの種類に応じて、発行元への報告やリポジトリ内のアラートにつながります。

### アクションプラン
- Cloudflare Access service token を利用している場合は、secret scanning のアラートを確認し、該当トークンが検出されたら失効・ローテーションしてください。
- アラートを受け取ったチームは、該当するシークレットをコードや履歴から除去し、漏えい範囲を調査してください。
- ユーザーシークレットはパブリック・プライベート両方でアラート対象です。パートナーシークレットの自動報告はパブリックリポジトリで行われます。

## Public monitoring alerts now have direct links

**URL:** https://github.blog/changelog/2026-11-12-public-monitoring-alerts-now-have-direct-links

### 要約
Public monitoring の各アラートに、個別のアラートを開く直接リンクが追加されました。GitHub Enterprise Cloud の Public monitoring 画面でアラート番号をクリックして詳細を開き、URL をブックマークしたり、アクセス権のあるチームメンバーと共有したりできます。

### ユーザーにとって良いこと
アラートへのリンクを共有・保存できるため、チームで調査対象を特定しやすくなり、後から同じアラートに戻る手間も減ります。

### アクションプラン
- GitHub Enterprise Cloud で GitHub Secret Protection または GitHub Advanced Security を利用している場合は、Public monitoring のアラート番号から個別ページを開いてください。この機能は追加料金なしで利用できます。
- 調査や対応を依頼する際は、アラートの直接リンクをブックマークまたはアクセス権のあるチームメンバーと共有してください。

- [Public monitoring alerts now have direct links](https://github.blog/changelog/2026-11-12-public-monitoring-alerts-now-have-direct-links)
