## Upcoming deprecation of selected GitHub Copilot models in December

**URL:** https://github.blog/changelog/2026-11-13-upcoming-deprecation-of-selected-github-copilot-models-in-december

### 要約
GitHub Copilot のチャット、インライン編集、Ask / Agent モード、コード補完などで、次のモデルが 2026年12月14日に廃止されます: Claude Fable 5、Claude Haiku 4.5、Gemini 3.8 Flash、Gemini 4 Argon、Grok 4.6、Kimi K3。推奨代替モデルは順に Claude Fable 5.2、Claude Haiku 5.5、Gemini 4 Hydrogen、Gemini 4 Carbon、Grok 4.7、Kimi K3 は後日発表です。Claude Haiku 4.5 は個人向け Copilot 年間プランでは引き続き利用でき、この廃止の対象外です。

### ユーザーにとって良いこと
代替モデルへ切り替えることで、Copilot の各機能や連携ワークフローを廃止後も継続して利用できます。Business / Enterprise では、既定のモデル有効化設定が有効なら推奨モデルが自動で有効になります。

### アクションプラン
- 2026年12月14日までに、Copilot の設定や連携で廃止対象モデルを指定していないか確認し、推奨モデルへ切り替えてください。
- Kimi K3 を利用している場合は、代替モデルの発表後に移行先を選んでください。
- Copilot Business / Enterprise の管理者はモデルポリシーを確認してください。全体の既定設定を無効にしている場合は、Copilot 設定から代替モデルへのアクセスを有効にする必要があります。代替モデルを明示的に無効化している場合も、必要に応じて設定を変更してください。
- 廃止後に対象モデルを手動で削除する必要はありません。個人向け Copilot 年間プランの Claude Haiku 4.5 は引き続き利用できます。

## GitHub Enterprise Server support in the GitHub Copilot app

**URL:** https://github.blog/changelog/2026-11-13-github-enterprise-server-support-in-the-github-copilot-app

### 要約
GitHub Copilot app で GitHub Enterprise Server（GHES）のアカウントを追加し、リモートリポジトリ、issue、pull request を扱えるようになりました。これまでオプトインのプレビューだった機能が一般提供となり、Copilot app 1.2.0 以降で利用できます。GHES ではクラウドセッションは利用できません。

### ユーザーにとって良いこと
GHES 上の開発作業を Copilot app に取り込み、リポジトリや issue、pull request を一か所から扱えます。プレビューへのオプトインなしで、対応バージョンのアプリから利用できます。

### アクションプラン
- GitHub.com または GHE.com アカウントで先にサインインし、Copilot app の **Settings > Accounts > Add account** から GHES アカウントを追加してください。
- Copilot app が 1.2.0 以降であることを確認してください。GHES アカウントではクラウドセッションを利用できない点に留意してください。

## Gemini 4 Hydrogen in GitHub Copilot

**URL:** https://github.blog/changelog/2026-11-13-gemini-4-hydrogen-in-github-copilot

### 要約
Google の最新 Flash モデル Gemini 4 Hydrogen が GitHub Copilot で一般提供されました。高速なエージェント型コーディング、ツール利用、複数ステップのワークフロー向けに設計され、Gemini 3.8 Flash より指示追従が改善されています。提供対象は Copilot Pro、Pro+、Max、Business、Enterprise で、利用量ベースの課金ではプロバイダーの標準料金が適用されます。

### ユーザーにとって良いこと
複数ステップの作業やツールを使うコーディングタスクで、高速なモデルを Copilot の各種クライアントから選択できます。段階的にロールアウトされるため、利用可能になった環境からモデルピッカーで選べます。

### アクションプラン
- 対象プランでは、VS Code、Visual Studio、Copilot CLI、Copilot coding agent、Copilot app、github.com、GitHub Mobile、JetBrains IDE、Xcode、Eclipse、Copilot SDK のモデルピッカーで Gemini 4 Hydrogen を選択してください。まだ表示されない場合はロールアウトを待ってください。
- Copilot Enterprise / Business の管理者は、モデルポリシーを確認してください。モデルの既定有効化が無効、または本モデルが明示的に無効化されている場合は、必要に応じてアクセスを有効にしてください。
- 利用量ベースの課金を使う場合は、プロバイダー標準料金が適用されるため、モデルと料金の情報を確認してください。

## Manage AI Scan for repositories using the REST API

**URL:** https://github.blog/changelog/2026-11-13-manage-ai-scan-for-repositories-using-the-rest-api

### 要約
パブリックプレビューとして、REST API からリポジトリ向け AI Scan の有効・無効を組織およびリポジトリ単位で管理できるようになりました。`repository_scan` 設定を `GET` / `PATCH /orgs/{org}/code-scanning/ai-scan` または `GET` / `PATCH /repos/{owner}/{repo}/code-scanning/ai-scan` で扱えます。AI Scan を有効にしてもスキャンは開始されず、ユーザーが手動で実行します。スキャンごとに GitHub Code Security AI クレジットを消費します。

### ユーザーにとって良いこと
組織やリポジトリごとの設定をスクリプトや Infrastructure as Code でまとめて管理でき、個別に設定画面を操作する手間を減らせます。組織で有効化した場合、リポジトリは設定を継承しつつ個別にオプトアウトできます。

### アクションプラン
- 組織オーナーまたはセキュリティマネージャーは、組織またはリポジトリ向けの AI Scan エンドポイントに `repository_scan: enabled` / `disabled` を指定して設定してください。リポジトリ管理者は、組織で有効な場合に個別リポジトリをオプトアウトできます。
- 既存の `pr_scan` と `repository_scan` は同じリクエストで更新できます。いずれかの変更が拒否されるとリクエスト全体が `422` となり、両方とも変更されません。
- AI Scan は対象リポジトリの書き込み権限を持つユーザーがオンデマンドで実行します。スキャン実行時に GitHub Code Security AI クレジットを消費する点を利用者に周知してください。
- 利用には、組織所有のパブリックリポジトリ、または GitHub Code Security / GitHub Advanced Security を備えたプライベート・内部リポジトリが必要です。Enterprise のポリシーで AI Scan が許可されていることも確認してください。GitHub Enterprise Server は対象外です。
