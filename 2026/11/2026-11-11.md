## Issue types and fields are available for personal accounts

**URL:** https://github.blog/changelog/2026-11-11-issue-types-and-fields-are-available-for-personal-accounts

### 要約
個人アカウントが所有するリポジトリで、issue types と issue fields が一般提供されました。個人アカウントの設定で種類・フィールドをカスタマイズでき、issue や Projects での設定、カスタムビュー、複数 issue の一括更新に利用できます。issue types と fields は REST / GraphQL API と webhook でも管理でき、issue から直接ラベルやマイルストーンを作成できます。

### ユーザーにとって良いこと
個人開発者やオープンソースメンテナーも、複数のリポジトリにまたがって issue の分類や優先度などを一貫して管理できます。必要なラベルやマイルストーンも issue 画面から作成できるため、作業中の画面を離れる手間が減ります。

### アクションプラン
- 必要に応じて個人アカウントの「Planning」設定から issue types と issue fields をカスタマイズしてください。各項目は最大 25 個まで作成できます。
- issue 作成・編集時に種類やフィールドを設定し、Projects のカスタムビューや一括更新に活用してください。
- issue の作成・編集時に見つからないラベルやマイルストーンがあれば、issue 画面から直接作成してください。
- 自動化する場合は REST / GraphQL API と webhook を使って issue types と fields を管理してください。この機能は個人アカウント所有リポジトリで一般提供されています。

## GitHub App support for Enterprise Copilot seat management

**URL:** https://github.blog/changelog/2026-11-10-github-app-support-for-enterprise-copilot-seat-management

### 要約
Enterprise GitHub Apps が、エンタープライズレベルの Copilot seat management API を呼び出せるようになりました。新しい fine-grained permission「Enterprise Copilot license management」を付与すると、ユーザーやエンタープライズチームへの Copilot シート割り当てをアプリから管理できます。

### ユーザーにとって良いこと
企業は GitHub App を使って Copilot シートの割り当てを自動化でき、ユーザーやチームの追加・変更に応じたライセンス管理を効率化できます。

### アクションプラン
- Copilot シート管理を自動化する場合は、Enterprise GitHub App に「Enterprise Copilot license management」権限を付与してください。
- アプリからエンタープライズの Copilot seat management API を利用し、ユーザーやチームへのシート割り当てを管理してください。
- 権限は fine-grained permission として提供されるため、利用するアプリに必要な権限を設定してください。
