## CodeQL 2.27.4 improves accuracy and query metadata

**URL:** https://github.blog/changelog/2026-11-04-codeql-2-27-4-improves-accuracy-and-query-metadata

### 要約
CodeQL 2.27.4 では、Java/Kotlin のログ・パスインジェクションクエリの認識範囲が広がり、Rust や C/C++ の複数クエリで誤検知が減りました。また、正規表現関連のクエリに付与される CWE-730 メタデータが修正され、CLI はシンボリックリンク経由でパックのルート外に解決されるファイルを除外して警告するようになりました。

### ユーザーにとって良いこと
脆弱性の検出精度が向上し、意図的なコードや安全化処理に対する誤検知を減らせます。CodeQL パックの公開・バンドル時にはルート外ファイルの混入も防ぎやすくなります。

### アクションプラン
- GitHub.com の code scanning には新しい CodeQL バージョンが自動展開されます。GitHub Enterprise Server は 3.24 に含まれる予定です。
- 古い GHES で CodeQL を手動管理している場合は、必要に応じて 2.27.4 へアップグレードしてください。
- CodeQL パックをバンドルまたは公開する場合は、シンボリックリンク先がパックのルート内にあることを確認してください。ルート外のファイルは CLI により除外されます。

## GitHub Copilot is now available in Xcode’s coding assistant

**URL:** https://github.blog/changelog/2026-11-04-github-copilot-is-now-available-in-xcodes-coding-assistant

### 要約
GitHub Copilot が Xcode 組み込みの coding assistant から利用できるようになり、Xcode 27.3 beta 以降でパブリックプレビューとして提供されます。従来の GitHub Copilot for Xcode 拡張機能も別の選択肢として引き続き利用できます。

### ユーザーにとって良いこと
既存の Xcode 作業環境を離れずに Copilot を利用でき、組み込み機能と従来の拡張機能から好みのワークフローを選べます。すべての Copilot プランが対象です。

### アクションプラン
- 試用する場合は Apple Developer Downloads から Xcode 27.3 beta を入手し、macOS Tahoe 26.6 以降の Mac で **Xcode > Settings > Intelligence** を開いて GitHub Copilot を設定してください。
- パブリックプレビューとして提供中の機能です。従来の GitHub Copilot for Xcode 拡張機能とは別の連携方法です。

## BYOK and enterprise custom models in the Copilot usage API

**URL:** https://github.blog/changelog/2026-11-03-byok-and-enterprise-custom-models-in-the-copilot-usage-api

### 要約
Copilot usage metrics API に、開発者が設定したローカル BYOK の利用状況と、組織・Enterprise が設定したカスタムモデルの利用状況を識別する項目が追加されました。これらはユーザー単位と集計単位の1日・28日レポートで確認でき、既存の利用総数は変更されません。

### ユーザーにとって良いこと
Copilot 提供モデル、独自プロバイダーのキー、ローカルモデルの利用を区別でき、利用ポリシーの確認や費用分析をより正確に行えます。サーバー側で観測する Enterprise カスタムモデルは、IDE を含むすべてのクライアントで集計されます。

### アクションプラン
- レポート連携を更新する場合は、`used_local_byok`、`totals_by_local_byok`、ローカル BYOK のアクティブユーザー指標、および `totals_by_client[].totals_by_model[].is_custom_enterprise_model` を利用してください。
- 利用者を識別・集計するときは、ローカル BYOK 指標がクライアントテレメトリに依存し、テレメトリ無効時や一部プロバイダーで過少計上となる点を考慮してください。カスタムモデル識別子は過去の日付には遡及適用されません。
- API の利用には Copilot usage metrics policy が有効であることと、Enterprise owner、Enterprise billing manager、Organization owner、または Copilot Metrics 閲覧権限を付与されたカスタムロールなど、必要なアクセス権が必要です。
- 既存の総数に BYOK 利用はすでに含まれています。追加指標と既存総数を合算して二重計上しないようにしてください。
