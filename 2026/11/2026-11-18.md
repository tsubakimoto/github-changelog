## Connect Supabase, Box, Calendly, and more to Copilot

**URL:** https://github.blog/changelog/2026-11-18-connect-supabase-box-calendly-and-more-to-copilot

### 要約
GitHub-verified MCP サーバーを使って、Box、Buildkite、Calendly、ClickUp、Mixpanel、Supabase、Webflow、Wix の 8 サービスを Copilot に接続できるようになりました。接続は Copilot アプリ、Copilot CLI、VS Code、github.com から設定でき、公開プレビューとして提供されます。

### ユーザーにとって良いこと
チームが日常的に使うコンテンツ管理、ビルド、スケジュール、分析、データベースなどの情報を Copilot から参照し、関連作業を同じセッションで進められます。

### アクションプラン
- 利用したいサービスを Copilot の Customize 画面、Copilot CLI の `/mcp` の Connectors タブ、VS Code の Agents > Customizations、または Copilot customization ページから接続してください。
- Copilot Business／Enterprise では、管理者が Editor preview features ポリシーを有効にしてください。MCP 許可リストを個別指定している場合は、新しいコネクターを追加してください。
- Box MCP アクセスなど、サービス側で管理者による有効化が必要な場合は、そのサービスの設定も確認してください。

## Gemini 4 Neon in GitHub Copilot

**URL:** https://github.blog/changelog/2026-11-18-gemini-4-neon-in-github-copilot

### 要約
Gemini 4 Neon が GitHub Copilot で一般提供されました。エージェント型コーディング、複数段階のツール利用、知識作業向けに設計され、Google によると Gemini 4 Carbon に近い品質をより低いタスクあたりトークンコストで提供します。

### ユーザーにとって良いこと
応答速度や不要な変更の少なさを重視する作業で、新たなモデルを選択できます。従量課金で、料金はプロバイダーのリスト価格に基づきます。

### アクションプラン
- Copilot Pro+、Max、Business、Enterprise のユーザーは、モデルピッカーで Gemini 4 Neon を選択してください。段階的にロールアウトされるため、表示されない場合は後日再確認してください。
- Copilot Business／Enterprise 管理者はモデルポリシーを確認してください。新しいモデルの既定有効化を停止している場合、またはこのモデルを個別に無効化している場合は、必要に応じて利用を許可してください。
- 利用前に従量課金の適用条件とモデル価格を確認してください。

## Security risk assessments run automatically on GitHub Team

**URL:** https://github.blog/changelog/2026-11-18-security-risk-assessments-run-automatically-on-github-team

### 要約
GitHub Team の組織で、セキュリティリスク評価が自動的に実行されるようになりました。組織管理者とセキュリティマネージャーは、無料の評価結果から露出した認証情報やコードの脆弱性を確認できます。

### ユーザーにとって良いこと
組織のリスク状況を把握し、見つかった問題の優先順位を決めて対応できます。評価が自動実行されるため、開始操作や追加料金なしでリスクの確認に取りかかれます。

### アクションプラン
- GitHub Team の組織管理者またはセキュリティマネージャーは、コードセキュリティおよびシークレットのリスク評価結果を確認してください。
- 検出された認証情報の露出や脆弱性をトリアージし、組織のリスクに応じて修正の優先順位を決めてください。

## Customize GitHub Copilot for your team

**URL:** https://github.blog/changelog/2026-11-18-customize-github-copilot-for-your-team

### 要約
Copilot のチームカスタマイズが一般提供になり、チームのメンテナーと組織オーナーは、承認した Agent Plugins をチームの既定として設定できるようになりました。設定したプラグインは VS Code、GitHub Copilot アプリ、Copilot CLI でチームの直接メンバーに既定で有効になりますが、子チームのメンバーには継承されません。

### ユーザーにとって良いこと
メンバーごとに同じプラグインを設定する手間を省き、チームで推奨する Copilot のカスタマイズを共有できます。メンバーはポリシーで許可されていれば、チームのプラグインを個別に無効化できます。

### アクションプラン
- Copilot Business／Enterprise のチームメンテナーまたは組織オーナーは、github.com の対象チームにある Customize Copilot タブから、利用するマーケットプレイスを追加してプラグインをチームの既定に設定してください。
- チームの既定は任意です。チームメンバーや子チームへの適用範囲を確認し、必要なチームごとに設定してください。
- 組織および Enterprise のポリシーがチーム設定より優先されます。許可するマーケットプレイスや必須・ブロック対象のプラグインを管理ポリシーと合わせて確認してください。
