## Dependabot alerts will pause on inactive repositories

**URL:** https://github.blog/changelog/2026-11-10-dependabot-alerts-will-pause-on-inactive-repositories

### 要約
2026年12月8日から、過去1年間に活動がない多くのリポジトリでは Dependabot alerts が自動的にオフになります。既存のアラートは削除されずアーカイブされ、リポジトリへの push または設定でアラートを再度オンにすると復元されます。GitHub.com の全プランと、データレジデンシーを含む GitHub Enterprise Cloud が対象で、GitHub Enterprise Server は対象外です。

### ユーザーにとって良いこと
開発中のリポジトリにアラート処理を集中させることで、Dependabot の速度と信頼性を保ちやすくなります。アラートは復元できるため、休止中のリポジトリで過去の検出結果が失われることもありません。

### アクションプラン
- 2026年12月8日までに、Dependabot alerts を維持する必要があるリポジトリの活動状況を確認してください。
- 対象リポジトリでアラートを維持するには、リポジトリに push するか、リポジトリ設定から Dependabot alerts を再度オンにしてください。再有効化するとアーカイブ済みアラートが復元され、1年間の活動期間がリセットされます。
- この変更は対象プラン・対象環境に自動適用されます。Dependabot alerts を有効にする強制セキュリティ構成が適用されたリポジトリ、および管理者がアラートを切り替えられないエンタープライズポリシーの対象リポジトリは除外されます。GitHub Enterprise Server には適用されません。
