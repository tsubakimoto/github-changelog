## Self-service credential revocation for incident response

**URL:** https://github.blog/changelog/2026-06-24-self-service-credential-revocation-for-incident-response

### 要約
GitHub Enterprise owners 向けに、侵害インシデント対応のための一括 credential revocation 機能が追加されました。特定ユーザーまたは enterprise 全体に対して、SSO authorization の revoke、token/SSH key の削除、組織単位の SSO authorization の確認と revoke を実行できます。

### ユーザーにとって良いこと
侵害が疑われるアカウントに対して、トークンや SSH key を個別に追いかけることなく素早く無効化できます。復旧と封じ込めの初動が短くなり、インシデント対応の手戻りを減らせます。

### アクションプラン
- Enterprise の incident response runbook に、新しい bulk revoke / delete 手順を追加してください。
- `Manage enterprise credentials` 権限を持つ担当者を明確にし、緊急時の連絡先と承認フローを更新してください。
- ⚠️ EMU アカウントの token/SSH key 削除は enterprise 単位の操作に限定されるため、対象範囲を事前に確認してください。
- revoke / delete 後の audit log と通知メールを確認する手順を運用に組み込んでください。

## Changes to model selection for Free and Student plans

**URL:** https://github.blog/changelog/2026-06-24-changes-to-model-selection-for-free-and-student-plans

### 要約
Copilot Free と Student plans では、Copilot auto model selection が既定かつ唯一の model selection になりました。自動選択がタスクごとに最適なモデルを割り当てるため、手動でのモデル選択は不要になります。あわせて、Microsoft-released models の (Preview) ラベルも終了します。

### ユーザーにとって良いこと
モデル選択の迷いが減り、すぐに作業を始めやすくなります。運用側も、プラン制約の範囲で自動的に最適化されるため、説明やサポートの負担を抑えられます。

### アクションプラン
- Free / Student 向けのヘルプ、オンボーディング資料、スクリーンショットから手動モデル選択の案内を削除してください。
- ⚠️ この変更は対象プランに自動適用されるため、利用者側での設定変更は不要です。
- 社内向けの Copilot 利用ガイドがある場合は、`auto` モード前提の説明に更新してください。
- Microsoft-released models の (Preview) 表記を前提にした運用チェックや文言が残っていないか確認してください。
