## Copilot usage metrics now include more of your active users

**URL:** https://github.blog/changelog/2026-06-15-copilot-usage-metrics-now-include-more-of-your-active-users

### 要約
Copilot usage metrics API が、クライアント側テレメトリに加えてサーバー側テレメトリも使うようになり、これまでレポートに出てこなかったアクティブユーザーをより多く含めるようになりました。これにより、Enterprise の単日および 28 日レポートの DAU が実態に近づきますが、詳細な IDE / feature / LOC の内訳はまだ空欄のまま残る場合があります。

### ユーザーにとって良いこと
Copilot の利用状況がより正確になり、実際に使っているのにレポートから抜けていたユーザーを把握しやすくなります。課金・利用分析・サポート対応での「見えないユーザー」のズレが減り、データの整合性が上がります。

### アクションプラン
- Copilot usage metrics API の DAU と activity log / billing の差分を確認し、以前よりユーザー数が増える前提でダッシュボードや監視の閾値を見直してください。
- `totals_by_ide` や `totals_by_feature` などの詳細内訳に未集計が増える可能性があるため、レポート利用者へ「総数は増えるが詳細が空欄になりうる」ことを周知してください。
- 変更は自動適用です。明示的なオプトインは不要ですが、社内説明資料や運用手順の文言は更新してください。
