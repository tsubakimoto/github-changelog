## IP allow list coverage for EMU namespaces in general availability

**URL:** https://github.blog/changelog/2026-06-08-ip-allow-list-coverage-for-emu-namespaces-in-general-availability

### 要約
GitHub Enterprise Cloud の Enterprise Managed Users (EMU) で、ユーザー namespace に対して GitHub のネイティブな IP allow list を適用できるようになりました。これにより、EMU 配下のリポジトリへのアクセスを、Web UI・Git・API を含めて許可済み IP のみに制限できます。

### ユーザーにとって良いこと
企業のネットワーク制御を、EMU のユーザー所有リポジトリにも一貫して適用できます。PAT、GitHub App トークン、SSH キーまでまとめて保護できるため、監査要件やゼロトラスト運用に合わせやすくなります。

### アクションプラン
- EMU を利用している Enterprise Cloud 組織で、ユーザー namespace のリポジトリにも IP allow list を適用する前提に運用を見直してください。
- GitHub の IP allow list 設定を、社内ネットワークや踏み台経由のアクセス元 IP に合わせて更新してください。
- ⚠️ Web UI、Git、API、PAT、GitHub App トークン、SSH キーのすべてが対象になるため、外部ネットワークからの自動化や保守作業に影響がないか確認してください。
- オプトインは不要です。GA 提供のため、対応条件を満たす EMU 環境で利用できます。
