## Claude Opus 4.8 (fast mode) is now in preview for GitHub Copilot

**URL:** https://github.blog/changelog/2026-06-29-claude-opus-4-8-fast-mode-is-now-in-preview-for-github-copilot

### 要約
Claude Opus 4.8 の fast mode が GitHub Copilot でプレビュー提供されました。通常版と同等の知能を保ちながら出力速度を大きく改善し、対話的なコーディングやエージェント的な作業での応答性を高めます。

### ユーザーにとって良いこと
待ち時間が短くなるため、補完やエージェント実行のフィードバックループが速くなります。Copilot を日常的に使うチームほど、体感の生産性向上が見込めます。

### アクションプラン
- Copilot Pro+ / Max / Business / Enterprise の利用者で fast mode を試し、既存モデルとの応答速度と品質を比較してください。
- Copilot Business / Enterprise の管理者は、Copilot 設定で Claude Opus 4.8 fast mode のポリシーを有効化してください。これは **手動有効化** で、既定ではオフです。
- Copilot CLI、cloud agent、IDE など、どの操作経路で速度改善の恩恵が大きいかをチーム内で確認してください。

## Restrict issue creation to collaborators only

**URL:** https://github.blog/changelog/2026-06-29-restrict-issue-creation-to-collaborators-only

### 要約
リポジトリ管理者が、書き込み権限を持つ collaborator のみに issue 作成を制限できるようになりました。Issues、Comments、Discussions、Projects、Copilot など、複数の入口からの issue 作成を一括で抑止できます。

### ユーザーにとって良いこと
不要な issue 作成やスパムを減らし、メンテナが管理しやすい issue フローを保てます。PR 作成の権限制御と合わせて、公開リポジトリの運用ルールをそろえやすくなります。

### アクションプラン
- リポジトリの `Settings > Features > Issues` で、必要なリポジトリに対して `Creation allowed by: Collaborators only` を設定してください。これは **リポジトリ単位の手動設定** です。
- 公開リポジトリで、外部 contributor の issue 受付を別の窓口（Discussion など）へ誘導する運用に切り替えるか検討してください。
- 既存の README、CONTRIBUTING、テンプレート文言が「誰でも issue を作成できる」前提になっていないか確認してください。
