## GitHub Copilot in Visual Studio Code, May releases

**URL:** https://github.blog/changelog/2026-06-03-github-copilot-in-visual-studio-code-may-releases

### 要約
VS Code の Copilot は、5 月から 6 月初旬にかけてのリリースで、Agents window の Stable preview 化や remote agents の preview、BYOK の air-gapped 対応など、エージェント中心の作業に向けて大きく強化されました。セッション同期、複数セッションの同時利用、モデルごとの役割分担の設定、ブラウザや Markdown まわりの改善も含まれます。

### ユーザーにとって良いこと
エージェントを使った長めの作業を、VS Code 内でより安全かつ継続的に進めやすくなります。モデル選択やセッション管理の柔軟性が上がり、レビューや検証の流れも扱いやすくなります。

### アクションプラン
- VS Code を最新版に更新し、Agents window と remote agents の preview を試してください。
- BYOK を使っている場合は、air-gapped 環境での利用可否と model policy を確認してください。
- utility tasks に使う model の割り当てを見直し、commit message や intent detection の運用を整理してください。
- セッション同期と複数セッション表示を、レビューや並行調査の手順に組み込んでください。
