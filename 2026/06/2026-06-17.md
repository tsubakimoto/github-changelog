## Read remote repository content with GitHub CLI

**URL:** https://github.blog/changelog/2026-06-17-read-remote-repository-content-with-github-cli

### 要約
`gh repo read-file` と `gh repo read-dir` が追加され、リポジトリを clone しなくてもターミナルからファイルやディレクトリの内容を確認できるようになりました。公開・非公開の両方に対応し、GitHub CLI v2.95.0 以降で利用できます。

### ユーザーにとって良いこと
README や設定ファイルの確認が速くなり、複数リポジトリの横断調査や自動化がしやすくなります。AI エージェントやスクリプトにも組み込みやすくなります。

### アクションプラン
- GitHub CLI を v2.95.0 以上に更新してください。
- 既存の調査スクリプトやエージェントで、clone 前提の処理を `gh repo read-file` / `gh repo read-dir` に置き換えてください。
- これは自動追加機能です。利用するだけでよく、明示的な有効化は不要です。

### リファレンス
- [Read remote repository content with GitHub CLI](https://github.blog/changelog/2026-06-17-read-remote-repository-content-with-github-cli)

## Secret scanning updates – June 2026

**URL:** https://github.blog/changelog/2026-06-17-secret-scanning-updates-june-2026

### 要約
Secret scanning の検出対象が拡大され、新しいパートナー秘密、push protection の既定対象、validity checks、拡張メタデータが追加されました。GitLab、Cloudsmith、Slack、Supabase、Datadog などのシークレット検出が強化されています。

### ユーザーにとって良いこと
漏えいした認証情報をより早く、より正確に見つけられるようになります。push protection で未然に防げるケースも増え、対応優先度の判断もしやすくなります。

### アクションプラン
- 検出対象が増えた前提で、既存リポジトリの secret scanning アラートを再確認してください。
- push protection で既定ブロックされるトークンが増えたため、CI やローカル開発フローの影響を確認してください。
- これは自動適用です。設定変更は不要ですが、社内の秘密情報管理ルールは更新してください。

## Enterprise-managed settings now support bypass permission controls

**URL:** https://github.blog/changelog/2026-06-17-enterprise-managed-settings-now-support-bypass-permission-controls

### 要約
Enterprise-managed settings に `disableBypassPermissionsMode` が追加され、Copilot CLI と VS Code が権限プロンプトを自動でスキップしないよう制御できるようになりました。`copilot/managed-settings.json` が新しい推奨パスで、既存の `.github/copilot/settings.json` も後方互換があります。

### ユーザーにとって良いこと
管理者が AI ツールの自動承認を抑止できるため、誤実行や意図しないコマンド実行のリスクを減らせます。組織のセキュリティ標準を一元的に適用しやすくなります。

### アクションプラン
- `.github-private/.github/copilot/settings.json` または `copilot/managed-settings.json` に `disableBypassPermissionsMode: "disable"` を追加してください。
- Enterprise の Agents ページで AI controls が反映されているか確認してください。
- これは Enterprise 管理下のユーザーに自動配布されます。影響を受けるチームへ権限挙動の変更を周知してください。

### リファレンス
- [Enterprise-managed settings now support bypass permission controls](https://github.blog/changelog/2026-06-17-enterprise-managed-settings-now-support-bypass-permission-controls)

## Auto mode in Copilot Chat available for all users

**URL:** https://github.blog/changelog/2026-06-17-auto-mode-in-copilot-chat-available-for-all-users

### 要約
Copilot Chat の auto モデル選択が全ユーザー向けに一般提供されました。リクエストの複雑さとモデルの稼働状況に応じて、Claude Sonnet 4.6 や GPT-5.4 系などへ動的にルーティングされます。

### ユーザーにとって良いこと
モデル選択の手間を減らしつつ、品質とコストのバランスを取りやすくなります。使用モデルは後から確認でき、必要なら都度切り替えられます。

### アクションプラン
- Copilot Chat の既定モデル運用を見直し、auto 利用時の案内を更新してください。
- 使用モデルの確認方法をチームに共有し、必要な場面では手動モデル選択へ切り替えてください。
- 有料プランでは 10% 割引が適用されるため、利用コストの見積もりを更新してください。

## Limit open pull requests for users without write access

**URL:** https://github.blog/changelog/2026-06-17-limit-open-pull-requests-for-users-without-write-access

### 要約
書き込み権限のないユーザーが開ける open pull request 数をリポジトリ単位で制限できるようになりました。draft PR は対象外で、信頼済み contributor は bypass list で除外できます。

### ユーザーにとって良いこと
大量の低品質 PR によるノイズを減らし、レビューや CI の負荷を抑えられます。メンテナーは高信号の変更に集中しやすくなります。

### アクションプラン
- 受け入れ可能な PR 数の上限をリポジトリごとに決めて設定してください。
- 信頼済み contributor を bypass list に追加し、不要な権限制限を避けてください。
- 外部コントリビューター向けの CONTRIBUTING や issue テンプレートに新しい制限を明記してください。

### リファレンス
- [Limit open pull requests for users without write access](https://github.blog/changelog/2026-06-17-limit-open-pull-requests-for-users-without-write-access)

## Agent finder for GitHub Copilot now available

**URL:** https://github.blog/changelog/2026-06-17-agent-finder-for-github-copilot-now-available

### 要約
Copilot の agent finder が利用可能になり、MCP サーバー、skills、agents、tools を手動で組み込まずに、必要な能力を検索・提案できるようになりました。ARD 仕様に基づき、選択した registry に対して discovery します。

### ユーザーにとって良いこと
タスクごとに最適な機能を見つけやすくなり、コンテキスト窓を不要なツールで埋めずに済みます。組織の許可した資源だけを見せられるため、統制もしやすくなります。

### アクションプラン
- 使わせたい MCP servers や agents を registry に登録し、検索される前提を整えてください。
- managed settings で discovery 対象を制限し、組織外の資源が見えないようにしてください。
- これは自動インストール機能ではありません。提案結果を確認してから導入してください。

- [Agent finder for GitHub Copilot now available](https://github.blog/changelog/2026-06-17-agent-finder-for-github-copilot-now-available)

## GitHub Copilot app generally available

**URL:** https://github.blog/changelog/2026-06-17-github-copilot-app-generally-available

### 要約
GitHub Copilot app が macOS / Windows / Linux で一般提供されました。issue や pull request からセッションを開始し、複数リポジトリで並列セッションを走らせ、integrated terminal や browser で検証できます。

### ユーザーにとって良いこと

### アクションプラン
- 開発者向けに GitHub Copilot app の導入手順を案内してください。
- Copilot Business / Enterprise では、Copilot CLI を policy で有効化してください。
- issue 起点のセッションや canvas を使う運用に合わせて、レビュー手順を更新してください。
