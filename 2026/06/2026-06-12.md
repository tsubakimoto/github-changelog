## Copilot code review: New configurations and controls

**URL:** https://github.blog/changelog/2026-06-12-copilot-code-review-new-configurations-and-controls

### 要約
Copilot code review に、organization-level の runner 制御、Copilot content exclusion の適用、`.github` 配下の custom instructions の文字数上限撤廃が追加されました。組織単位で runner type を統一できるため、複数リポジトリの設定をまとめやすくなっています。

### ユーザーにとって良いこと
レビュー実行基盤を組織で揃えやすくなり、運用のばらつきを減らせます。不要なファイルやディレクトリを除外できるため、Copilot が参照するコンテキストをより安全に管理できます。

### アクションプラン
- organization admin は、Copilot -> Runner type -> Runner type configuration で既定 runner を設定してください。これは organization 配下のリポジトリに適用されます。
- repository admin は、Copilot content exclusion の path-based rules を見直し、レビュー対象外にしたいファイルやディレクトリを設定してください。
- `.github/copilot-instructions.md` や `*.instructions.md` を長く運用している場合は、追加の制約を気にせず内容を拡張してください。これは自動適用の変更です。

## GitHub Actions: Minimum version enforcement timeline for self-hosted runners

**URL:** https://github.blog/changelog/2026-06-12-github-actions-minimum-version-enforcement-timeline-for-self-hosted-runners

### 要約
Self-hosted runner に対する GitHub Actions の version enforcement が再開され、登録には 2.329.0 以上、継続利用には公開後 30 日以内の更新が必要になります。段階的な brownout の後、GitHub Enterprise Cloud with Data Residency は 2026-07-31、GitHub Enterprise Cloud は 2026-09-25 に完全 enforcement へ移行します。

### ユーザーにとって良いこと
古い runner を早めに洗い出せるため、ジョブ停止や登録失敗を本番前に防ぎやすくなります。Actions 基盤の移行完了により、実行の信頼性と互換性が安定します。

### アクションプラン
- すべての self-hosted runner を最新のサポート版に更新してください。GitHub.com 上の GitHub Enterprise Cloud と Data Residency 付き環境が対象です。
- runner image、VM template、container image、デプロイ自動化を見直し、古いバージョンを再生成してください。
- ⚠️ auto-update を無効にしている runner は、30 日以内に手動更新できる運用へ切り替えてください。
- enterprise audit log で `register_self_hosted_runner` 系イベントを確認し、登録中の runner version を棚卸ししてください。
