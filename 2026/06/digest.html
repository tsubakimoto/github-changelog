重要アップデート（ピックアップ）

  • Updates to GitHub Copilot billing and plans - Copilot の課金体系とプラン構成が変わるため、コスト管理と契約内容の見直しが必要です。
  • GPT-4.1 deprecated - Copilot 全体で GPT-4.1 が廃止され、GPT-5.5 への移行対応が必須になります。
  • GPT-5.2 and GPT-5.2-Codex deprecated - 旧 GPT-5.2 系が廃止され、モデル指定を含む既存ワークフローの更新が必要です。
  • Copilot SDK is now generally available - Copilot の agentic engine を自社アプリへ組み込める基盤が GA になりました。
  • Upcoming breaking changes for npm v12 - npm v12 の破壊的変更に備え、CI とパッケージ公開フローの検証が必要です。
  • GitHub Agentic Workflows is now in public preview - エージェント処理をワークフローとして定義でき、自動化の設計方針に影響します。
  • GitHub Models is no longer available to new customers - 新規利用の停止により、モデル検証基盤の代替検討が必要になります。
  • GitHub Copilot app generally available - Copilot app が GA となり、エージェント中心の作業導線を本番運用に載せられます。
  • Safer pull_request_target defaults for GitHub Actions checkout - Actions のセキュリティ既定値が変わるため、既存ワークフローの挙動確認が必要です。
  • Upcoming cloud data retention policy for closed security alerts - クローズ済みセキュリティアラートの保持期間が変わり、監査・記録運用に影響します。
