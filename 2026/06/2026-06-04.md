## Fix with Copilot for failing Actions now in Pro, Pro+, and Max

**URL:** https://github.blog/changelog/2026-06-04-fix-with-copilot-for-failing-actions-now-in-pro-pro-and-max

### 要約
GitHub Actions の失敗ジョブに対して、Copilot cloud agent へワンクリックで修正依頼できるようになりました。ワークフロー実行ログから起動すると、Copilot が原因を調べ、ブランチに修正を push し、完了後にレビュー依頼します。

### ユーザーにとって良いこと
テスト失敗や lint エラーのような反復作業を Copilot に任せやすくなり、開発者は本来の実装に集中できます。Actions の失敗対応が、手作業の切り分けからエージェント駆動の修正へ移りやすくなります。

### アクションプラン
- Actions の失敗対応フローで `Fix with Copilot` を試し、どの種類の失敗に向くか確認してください。
- ワークフロー実行ログからの利用を前提に、レビュー担当者への引き継ぎ手順を決めてください。
- 反映された修正が本当に妥当かを確認するため、CI 再実行の基準をチームで定めてください。

### リファレンス
- [Fix with Copilot for failing Actions now in Pro, Pro+, and Max](https://github.blog/changelog/2026-06-04-fix-with-copilot-for-failing-actions-now-in-pro-pro-and-max)

## Agent tasks REST API now available for Copilot Pro, Pro+, and Max

**URL:** https://github.blog/changelog/2026-06-04-agent-tasks-rest-api-now-available-for-copilot-pro-pro-and-max

### 要約
Copilot cloud agent のタスクを API から開始・追跡できる Agent tasks REST API が public preview で提供されました。外部の自動化から、リファクタリング、リリース準備、新規リポジトリのセットアップなどを流し込めます。

### ユーザーにとって良いこと
Copilot の実行を個別操作に閉じず、社内ポータルやスクリプトに組み込みやすくなります。定型作業をまとめて自動化しやすくなり、進捗確認も API で扱えます。

### アクションプラン
- 社内ポータルや自動化スクリプトで、Agent tasks REST API を呼び出す試作を作ってください。
- PAT や OAuth の認証方式を整理し、どの automation にどの token を使うか決めてください。
- まずはリファクタリングや release note 作成など、影響範囲が限定的な処理から導入してください。

### リファレンス
- [Agent tasks REST API now available for Copilot Pro, Pro+, and Max](https://github.blog/changelog/2026-06-04-agent-tasks-rest-api-now-available-for-copilot-pro-pro-and-max)

## Larger context windows and configurable reasoning levels for GitHub Copilot

**URL:** https://github.blog/changelog/2026-06-04-larger-context-windows-and-configurable-reasoning-levels-for-github-copilot

### 要約
Copilot で 100 万トークンの大きなコンテキストウィンドウと、深さを調整できる reasoning level が使えるようになりました。VS Code、Copilot CLI、GitHub Copilot app で利用でき、複雑な多ファイル作業や難しい調査に向いています。

### ユーザーにとって良いこと
長いコードベースや複数ファイルをまたぐ作業でも、文脈切れを起こしにくくなります。必要なときだけ深い推論を使えるので、普段は軽く、難所では強く使い分けできます。

### アクションプラン
- 日常タスクは既定の設定を使い、複雑な調査や大規模変更時だけ拡張コンテキストを選んでください。
- AI クレジット消費が増える前提で、利用基準をチーム内に明文化してください。
- VS Code、Copilot CLI、Copilot app のどの画面で使うかを決め、モデル選択手順を揃えてください。

### リファレンス
- [Larger context windows and configurable reasoning levels for GitHub Copilot](https://github.blog/changelog/2026-06-04-larger-context-windows-and-configurable-reasoning-levels-for-github-copilot)

## GitHub Copilot in Visual Studio — May update

**URL:** https://github.blog/changelog/2026-06-04-github-copilot-in-visual-studio-may-update

### 要約
Visual Studio 2026 の Copilot に、Plan agent、Skills パネル、複数ファイル変更の summary diff、コンテキスト使用量の表示、commit の直接添付などが追加されました。コミットメッセージのカスタム指示も、専用設定からリポジトリの Copilot custom instructions へ移動しています。

### ユーザーにとって良いこと
実装前の計画、差分確認、会話の圧縮、関連コミットの参照が 1 つの流れにまとまり、作業の見通しが良くなります。指示の置き場所が統一されるので、チームでの運用も揃えやすくなります。

### アクションプラン
- Plan agent を使って、実装前に markdown の計画ファイルを出す運用を試してください。
- Skills パネルで workspace と user profile の skill を棚卸しし、不要なものを整理してください。
- commit message のカスタム指示を `.github` 側の Copilot custom instructions に移し、既存設定との差分を確認してください。

- [GitHub Copilot in Visual Studio — May update](https://github.blog/changelog/2026-06-04-github-copilot-in-visual-studio-may-update)

## Enterprise Teams is now generally available

**URL:** https://github.blog/changelog/2026-06-04-enterprise-teams-is-now-generally-available

### 要約
Enterprise Teams が GitHub Enterprise Cloud で一般提供になりました。企業全体で 1 度定義した team を複数 org にまたがって再利用でき、レビュー担当、ruleset bypass、SCIM 連携、API 管理まで一元化できます。

### ユーザーにとって良いこと
同じ役割の team を org ごとに複製する必要がなくなり、運用の重複を減らせます。権限、通知、監査を enterprise 単位で揃えやすくなります。

### アクションプラン
- Enterprise account の People タブから enterprise team を作成し、既存 org team の重複を洗い出してください。
- ルールセットの bypass actor や PR reviewer の割り当てを enterprise team に寄せてください。
- SCIM や GitHub Apps を使う場合は、team 変更が監査ログに残る前提で自動化を見直してください。

- [Enterprise Teams is now generally available](https://github.blog/changelog/2026-06-04-enterprise-teams-is-now-generally-available)

## Copilot Chat brings richer context to pull requests

**URL:** https://github.blog/changelog/2026-06-04-copilot-chat-brings-richer-context-to-pull-requests

### 要約
github.com の pull request と diff 上で、Copilot Chat が richer context 付きで一般提供になりました。差分の横でチャットしながら inline edit でき、関連する PR や repository の文脈をより速く取り込めます。

### ユーザーにとって良いこと
PR を見ながら説明、質問、編集を同じ画面で扱えるため、画面の行き来が減ります。レビューや修正の往復が短くなり、差分理解も進めやすくなります。

### アクションプラン
- PR レビュー時に `Ask about this diff` を使い、質問の入り口を標準化してください。
- inline edits を含むレビュー運用では、人間レビューとの役割分担を決めてください。
- github.com 上でのレビュー手順を更新し、チャットを差分確認の一部として扱ってください。

### リファレンス
- [Copilot Chat brings richer context to pull requests](https://github.blog/changelog/2026-06-04-copilot-chat-brings-richer-context-to-pull-requests)
