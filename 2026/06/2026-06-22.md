## New features and Claude as agent provider preview in JetBrains IDEs

**URL:** https://github.blog/changelog/2026-06-22-new-features-and-claude-as-agent-provider-preview-in-jetbrains-ides

### 要約
GitHub Copilot の JetBrains IDE 向け更新です。組織/Enterprise のカスタムエージェント利用、Copilot CLI でのキュー/割り込み送信、Agent Debug のログ要約、Claude をエージェントプロバイダとして使う公開プレビューなど、複数の新機能が追加されました。あわせて、モデルピッカーやクレジット表示、入力・差分・レンダリング周りの改善と不具合修正も含まれます。

### ユーザーにとって良いこと
チームで標準化したエージェントを IDE から直接使えるため、運用やレビューの一貫性が上がります。長時間の CLI タスクを中断せずに指示変更でき、JetBrains での作業効率と可視性も向上します。

### アクションプラン
- JetBrains IDE を使っている場合は GitHub Copilot プラグインを最新化し、新しいエージェント選択 UI を確認してください。
- 組織/Enterprise 管理者は、公開したいカスタムエージェントを GitHub 側で定義し、メンバーに配布されることを前提に運用ルールを整えてください。
- Copilot Business / Enterprise で Claude エージェントを使う場合は、管理者が Editor preview features policy を有効化してください。
- Copilot CLI を使うチームは、長時間実行中の turn に対して Queue / Steer / Stop-and-Send の使い分けを共有してください。
