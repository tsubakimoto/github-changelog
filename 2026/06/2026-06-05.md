## GPT-5.2 and GPT-5.2-Codex deprecated

**URL:** https://github.blog/changelog/2026-06-05-gpt-5-2-and-gpt-5-2-codex-deprecated

### 要約
Copilot の多くの体験で GPT-5.2 と GPT-5.2-Codex が非推奨になり、代替として GPT-5.5 と GPT-5.3-Codex が案内されています。Copilot Chat、inline edits、ask/agent mode、code completions に影響し、code review では GPT-5.2 が引き続き使えます。

### ユーザーにとって良いこと
サポート対象モデルへの移行先が明確になり、今後の運用を最新の推奨構成に揃えやすくなります。モデル選択のばらつきを減らし、互換性の問題を早めに解消しやすくなります。

### アクションプラン
- ⚠️ GPT-5.2 と GPT-5.2-Codex を参照しているワークフロー、スクリプト、評価設定を GPT-5.5 / GPT-5.3-Codex に更新してください。
- Copilot Enterprise を使っている場合は、管理者が model policy で代替モデルを有効化してください。
- github.com と VS Code の Copilot 設定で、必要なモデルが selector に表示されるか確認してください。

### リファレンス
- [GPT-5.2 and GPT-5.2-Codex deprecated](https://github.blog/changelog/2026-06-05-gpt-5-2-and-gpt-5-2-codex-deprecated)

## CodeQL 2.25.6 adds Swift 6.3.2 support and improves C# coverage

**URL:** https://github.blog/changelog/2026-06-05-codeql-2-25-6-adds-swift-6-3-2-support-and-improves-c-coverage

### 要約
CodeQL 2.25.6 で Swift 6.3.2 のサポートが追加され、C# 14 と .NET 10 の対応が完了しました。加えて、Java/Kotlin、C/C++、JavaScript/TypeScript、Python、Swift、Rust の機密情報検出や GitHub Actions 向けクエリが改善されています。

### ユーザーにとって良いこと
新しい言語機能やランタイムを使うリポジトリでも、code scanning の適用範囲を広げやすくなります。誤検知の減少や検出精度の改善で、セキュリティレビューのノイズも下げやすくなります。

### アクションプラン
- Swift 6.3.2、C# 14、.NET 10 を使うリポジトリで CodeQL の実行設定を更新してください。
- ⚠️ `actions/untrusted-checkout/critical` の見直しで一部アラートが checkout 位置に再表示されるため、再オープン分を確認してください。
- `actions/unpinned-tag` などの結果を再確認し、SHA-256 ピン留めの扱いが期待通りか検証してください。

## Enterprise-managed plugins in VS Code in public preview

**URL:** https://github.blog/changelog/2026-06-05-enterprise-managed-plugins-in-vs-code-in-public-preview

### 要約
Enterprise 管理者が定義した plugins、hooks、MCP 設定を、VS Code と Copilot CLI に配布できる public preview が始まりました。`.github-private/.github/copilot/settings.json` に置いた設定が、企業アカウント配下のユーザーへ自動適用されます。

### ユーザーにとって良いこと
初期セットアップや拡張機能のばらつきを減らし、組織標準の Copilot 体験を揃えやすくなります。custom agents や skills の配布も簡単になり、オンボーディングの手間を下げやすくなります。

### アクションプラン
- 管理者は `.github-private/.github/copilot/settings.json` に enterprise-managed plugins の定義を追加してください。
- VS Code と Copilot CLI の両方で、同じ baseline 設定が適用される前提で運用手順を見直してください。
- ⚠️ 自動インストールされる plugins、hooks、MCP 設定の範囲を事前に確認し、許可対象を絞ってください。

### リファレンス
