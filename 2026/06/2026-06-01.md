## Evaluation models in auto for individual plans

**URL:** https://github.blog/changelog/2026-06-01-evaluation-models-in-auto-for-individual-plans

### 要約
GitHub Copilot の auto モデル選択で、個人向けの非 Enterprise ユーザーにも evaluation models が提供されるようになりました。auto 選択時にこれらのモデルが使われる可能性があり、必要なら設定から無効化できます。

### ユーザーにとって良いこと
auto 選択を使うだけで、より広いモデル候補を試せるようになります。手動でモデルを切り替えなくても、Copilot の応答品質や挙動の改善を受け取りやすくなります。

### アクションプラン
- Copilot の設定を開き、evaluation models を auto 選択で使うかどうかを確認してください。
- 組織内で Copilot の応答の再現性を重視する場合は、auto 選択の利用方針と無効化手順をドキュメント化してください。
- サポートや運用担当は、評価用モデルが出力差分を生む可能性を前提に、検証手順を更新してください。

## Updates to GitHub Copilot billing and plans

**URL:** https://github.blog/changelog/2026-06-01-updates-to-github-copilot-billing-and-plans

### 要約
GitHub Copilot の usage-based billing が全プランで有効になり、消費した GitHub AI Credits に応じて課金されるようになりました。あわせて、Copilot code review が GitHub AI Credits に加えて GitHub Actions minutes も消費し、ユーザーレベルの予算管理や Copilot Max へのアップグレードも提供されています。

### ユーザーにとって良いこと
利用量に応じた課金と予算管理が明確になり、組織側でコストを細かく制御しやすくなります。Copilot code review の実行基盤や上限を調整できるため、使い過ぎの抑制と運用の見通しが改善します。

### アクションプラン
- ⚠️ Copilot code review の利用コストが AI Credits だけでなく Actions minutes にも及ぶため、月次の消費量と請求影響を確認してください。
- organization/admin 権限がある場合は、既定の Actions runner を設定して code review の実行先を統一してください。
- organizations / enterprises では user-level budget を設定し、上限通知と調整手順を billing 設定に反映してください。
- 個人利用やヘビーユーザー向けには、Copilot Max へのアップグレード可否と必要な included usage を確認してください。
- 新規サインアップ停止の影響を受ける場合は、導入案内や社内ドキュメントに現状を追記してください。
