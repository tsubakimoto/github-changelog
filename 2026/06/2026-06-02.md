## GPT-4.1 deprecated

**URL:** https://github.blog/changelog/2026-06-02-gpt-4-1-deprecated

### 要約
GitHub Copilot の全体で GPT-4.1 が非推奨になり、代替モデルとして GPT-5.5 が案内されています。Copilot Chat、inline edits、ask/agent mode、code completions まで影響するため、古いモデル前提の運用は見直しが必要です。

### ユーザーにとって良いこと
サポート対象のモデルに早く移行でき、Copilot の利用体験を最新の推奨構成に揃えやすくなります。組織側もモデル選択のばらつきを減らしやすくなります。

### アクションプラン
- ⚠️ GPT-4.1 を参照しているワークフロー、スクリプト、評価手順を GPT-5.5 に更新してください。
- Copilot Enterprise を使っている場合は、管理者がモデルポリシーで GPT-5.5 の利用を有効化してください。
- 個人設定と github.com / VS Code のモデルセレクタで、代替モデルが見えているか確認してください。

### リファレンス
- [GPT-4.1 deprecated](https://github.blog/changelog/2026-06-02-gpt-4-1-deprecated)

## Expanded technical preview availability for the GitHub Copilot app

**URL:** https://github.blog/changelog/2026-06-02-expanded-technical-preview-availability-for-the-github-copilot-app

### 要約
GitHub Copilot app の technical preview が、既存の Copilot Pro、Pro+、Business、Enterprise 利用者へ広く開放されました。Copilot Free の利用者は waitlist に登録でき、Pro+ 利用者は Copilot Max へのアップグレードも案内されています。

### ユーザーにとって良いこと
新しい Copilot app を早い段階で試せる範囲が広がり、エージェント中心の作業フローを先行評価できます。日常の作業がチャットや差分確認の管理へ移る前提で、体験を検証しやすくなります。

### アクションプラン
- 対象プランのユーザーは Copilot app をダウンロードして technical preview を試してください。
- Copilot Free のユーザーは waitlist に登録し、公開範囲の拡大に備えてください。
- チームで導入する場合は、エージェントの出力確認や diff レビューの運用を先に決めてください。

## Copilot SDK is now generally available

**URL:** https://github.blog/changelog/2026-06-02-copilot-sdk-is-now-generally-available

### 要約
GitHub Copilot SDK が一般提供になり、Copilot の agentic engine を自分のアプリケーションや開発ツールに組み込めるようになりました。計画、ツール呼び出し、ファイル編集、ストリーミング、マルチターンセッションまで、安定した API で利用できます。

### ユーザーにとって良いこと
独自の AI 開発体験をゼロからオーケストレーションしなくても、Copilot の実行基盤を再利用できます。社内ツールや顧客向け機能に、より短い経路でエージェント機能を追加できます。

### アクションプラン
- Copilot を組み込む社内ツールやサービスがあるなら、SDK の GA 版に置き換える検討を進めてください。
- 利用言語に応じて Node.js/TypeScript、Python などのパッケージを選び、既存の独自オーケストレーションを整理してください。
- 本番導入前に、セッション管理・ファイル編集・ツール実行の境界をテストしてください。

### リファレンス
- [Copilot SDK is now generally available](https://github.blog/changelog/2026-06-02-copilot-sdk-is-now-generally-available)

## Cloud and local sandboxes for GitHub Copilot now in public preview

**URL:** https://github.blog/changelog/2026-06-02-cloud-and-local-sandboxes-for-github-copilot-now-in-public-preview

### 要約
GitHub Copilot が、ローカルとクラウドの両方で動く isolated sandboxes を public preview で提供します。Copilot のツール実行、ファイル操作、ネットワークアクセスを、定義したポリシーの範囲内で安全に分離できます。

### ユーザーにとって良いこと
エージェントにコードやツールを触らせるときの安全性と分離性が高まり、企業導入しやすくなります。ローカル実行とクラウド実行の両面で、制御と柔軟性を両立しやすくなります。

### アクションプラン
- Copilot に実行させるコマンドやネットワークアクセスのポリシーを先に整理してください。
- public preview を試す前に、どのリポジトリや作業を sandbox に載せるかを決めてください。
- セキュリティ担当は、sandbox の境界で許可するファイル・通信・ツールの範囲をレビューしてください。

### リファレンス
- [Cloud and local sandboxes for GitHub Copilot now in public preview](https://github.blog/changelog/2026-06-02-cloud-and-local-sandboxes-for-github-copilot-now-in-public-preview)

## GitHub Copilot code review for Azure Repos is now in technical preview

**URL:** https://github.blog/changelog/2026-06-02-github-copilot-code-review-for-azure-repos-is-now-in-technical-preview

### 要約
Azure Repos で GitHub Copilot code review を on-demand で使える technical preview が始まりました。組織とリポジトリの両方で有効化すると、Pull Request から直接レビューを依頼でき、インラインでコメントが返されます。

### アクションプラン
- Azure DevOps 利用組織は technical preview への参加可否を確認してください。
- まずは一部のリポジトリで org / repo レベルの有効化と運用検証を行ってください。
- PR 依頼フローに Copilot code review を組み込む場合は、いつ人間レビューへ回すかも決めてください。

### リファレンス
- [GitHub Copilot code review for Azure Repos is now in technical preview](https://github.blog/changelog/2026-06-02-github-copilot-code-review-for-azure-repos-is-now-in-technical-preview)
