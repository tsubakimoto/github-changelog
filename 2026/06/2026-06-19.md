## AI credits consumed per user now in the Copilot usage metrics API

**URL:** https://github.blog/changelog/2026-06-19-ai-credits-consumed-per-user-now-in-the-copilot-usage-metrics-api

### 要約
Copilot usage metrics API のユーザーレポートに、`ai_credits_used` が追加されました。enterprise / organization の `users-1-day` と `users-28-day` レポートで、各ユーザーが消費した AI credits の合計を確認できます。

### ユーザーにとって良いこと
利用量と価値の関係を同じレポートで追いやすくなり、チームや組織ごとの AI credit 消費の偏りも把握しやすくなります。usage-based billing の予測や予算見積もりにも使いやすくなります。

### アクションプラン
- Copilot usage metrics API を取得している集計処理に `ai_credits_used` を追加してください。
- ダッシュボードや定期レポートで、ユーザー別の消費量を既存の利用指標と並べて表示してください。
- これは enterprise administrators と organization owners 向けの REST API です。アクセス権を持つ運用担当だけが参照できる前提で通知してください。
- `ai_credits_used` は feature / model / surface 別の内訳ではなく、請求総額そのものでもありません。請求確認は billing を参照してください。
