## GitHub Models is no longer available to new customers

**URL:** https://github.blog/changelog/2026-06-16-github-models-is-no-longer-available-to-new-customers

### 要約
GitHub Models は段階的な終了に入り、新規の organization / enterprise は新たに利用開始できなくなりました。既存ユーザーは現時点では影響を受けず、playground・API・モデルは継続利用できます。

### ユーザーにとって良いこと
既存利用者は急な停止を避けられ、移行準備の時間が確保されています。新規導入を検討していたチームは、代替候補を早めに見直せます。

### アクションプラン
- 既存の GitHub Models 利用状況を確認し、影響を受ける organization / enterprise を把握してください。
- これから AI モデル基盤を必要とする新規案件では、Azure AI Foundry などの代替案に切り替えてください。
- ⚠️ 完全終了の時期は未発表のため、移行計画と社内案内を先に整備してください。

- [GitHub Models is no longer available to new customers](https://github.blog/changelog/2026-06-16-github-models-is-no-longer-available-to-new-customers)

## GitHub Code Quality generally available July 20, 2026

**URL:** https://github.blog/changelog/2026-06-16-github-code-quality-generally-available-july-20-2026

### 要約
GitHub Code Quality は 2026-07-20 に public preview から一般提供へ移行し、有償プロダクトになります。Organization 全体への展開、品質ダッシュボード、coverage enforcement、quality scoring、API などの機能も追加されます。

### ユーザーにとって良いこと
コード品質の可視化とガードレールが強化され、maintainability / reliability / coverage を一元管理しやすくなります。大規模組織でも、組織単位での導入と統制がしやすくなります。

### アクションプラン
- 7/20 以降の課金（active committer 単位 + AI 利用 + Actions minutes）を前提に予算を見直してください。
- Code Quality を使わないリポジトリは、7/20 までに無効化して請求対象から外してください。
- 既存の quality gates、rulesets、Copilot code review、Actions の利用量を点検し、影響範囲をチームへ周知してください。

### リファレンス
- [GitHub Code Quality generally available July 20, 2026](https://github.blog/changelog/2026-06-16-github-code-quality-generally-available-july-20-2026)

## Organization-level enablement for GitHub Code Quality

**URL:** https://github.blog/changelog/2026-06-16-organization-level-enablement-for-github-code-quality

### 要約
Organization 管理者が、各リポジトリを個別設定せずに Code Quality を組織全体へ一括で有効化 / 無効化できるようになりました。Security 配下の organization settings に新しい "Code quality" セクションが追加されています。

### ユーザーにとって良いこと
大規模 organization でも導入作業が大幅に簡単になり、設定のばらつきを減らせます。統一的にロールアウトできるため、管理コストが下がります。

### アクションプラン
- Organization settings の Security > Code quality から、対象 organization で一括設定できることを確認してください。
- 組織全体で導入する場合は、事前に対象リポジトリと影響範囲を整理してください。
- これは public preview です。運用適用は段階的に行い、必要なら個別リポジトリ設定との整合を確認してください。

### リファレンス
- [Organization-level enablement for GitHub Code Quality](https://github.blog/changelog/2026-06-16-organization-level-enablement-for-github-code-quality)
