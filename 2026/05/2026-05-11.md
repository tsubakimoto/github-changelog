## Create repositories on the go with GitHub Mobile

**URL:** https://github.blog/changelog/2026-05-11-create-repositories-on-the-go-with-github-mobile

### 要約
GitHub Mobile から新しいリポジトリを直接作成できるようになりました。iOS では Home または Profile から、Android では Home または Profile の Repositories から作成できます。

テンプレート利用の有無に応じて、README、.gitignore、license、全ブランチの含有などの初期設定も選べます。

### ユーザーにとって良いこと
PC を開かなくても、移動中にすぐリポジトリを立ち上げられます。テンプレートや初期ファイルの選択もその場でできるため、最初のセットアップが速くなります。

### アクションプラン
- GitHub Mobile を最新バージョンに更新してください。
- モバイルから作成したリポジトリの初期構成（README、license、.gitignore）をチーム標準に合わせて確認してください。
- テンプレートを使う運用なら、どのテンプレートを Mobile から作るかをメンバーに共有してください。
