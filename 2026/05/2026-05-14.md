## Team-level Copilot usage metrics now available via API

**URL:** https://github.blog/changelog/2026-05-14-team-level-copilot-usage-metrics-now-available-via-api

### 要約
Copilot の使用状況をチーム単位で集計できる新しい user-teams レポートが REST API に追加されました。既存の per-user usage レポートと結合することで、アクティブユーザー数や completions、chats をチーム別に分析できます。

### ユーザーにとって良いこと
組織や Enterprise 全体の数字だけでなく、どのチームが Copilot を活用しているかを把握できます。導入促進や支援が必要なチームを特定しやすくなります。

### アクションプラン
- Enterprise 管理者または org owner は、`/copilot/metrics/reports/user-teams-1-day` を使う集計処理を追加してください。
- 既存の per-user usage レポートと `user_id` と `day` で結合し、チーム別にロールアップしてください。
- ⚠️ 5 人未満の Copilot seated users のチームはレポート対象外です。個人活動は per-user 側で確認してください。

## GitHub Actions: Upcoming image migrations

**URL:** https://github.blog/changelog/2026-05-14-github-actions-upcoming-image-migrations

### 要約
GitHub Actions の Arm64 ランナーイメージが GitHub 管理に移行され、Windows 2025 と macOS latest のラベル挙動にも変更が入ります。機能互換性は維持されますが、`runs-on` の指定先は今後の既定イメージに合わせて見直しが必要です。

### ユーザーにとって良いこと
Arm64 イメージは GitHub 直接管理になり、維持体制が明確になります。Windows と macOS の最新イメージへの移行も事前告知されるため、計画的に検証できます。

### アクションプラン
- Arm64 のワークフローはそのままで問題ありませんが、移行期間中の runner-images 更新状況を確認してください。
- Windows 2025 を使うワークフローは `windows-2025-vs2026` で事前検証し、VS 2022 維持が必要なら `windows-2022` に固定してください。
- macOS 15 を使い続けたいワークフローは `macos-15` を明示指定してください。

### リファレンス
- [GitHub Actions: Upcoming image migrations](https://github.blog/changelog/2026-05-14-github-actions-upcoming-image-migrations)

## GitHub Copilot app is now available in technical preview

**URL:** https://github.blog/changelog/2026-05-14-github-copilot-app-is-now-available-in-technical-preview

### 要約
GitHub Copilot app の technical preview が始まりました。Issue や pull request、プロンプト、既存セッションから開始でき、セッション内で計画・実装・レビュー・PR 化まで一連で進められます。

### ユーザーにとって良いこと
GitHub 上の実際の作業文脈から、そのまま agentic development を始められます。レビュー、検証、PR までの流れが統合されるため、作業の分断が減ります。

### アクションプラン
- Copilot Pro / Pro+ は早期アクセス登録を確認してください。
- Copilot Business / Enterprise は、プレビュー機能と Copilot CLI がポリシーで有効か管理者設定を確認してください。
- ⚠️ technical preview なので、導入範囲を限定し、運用手順を先に整えてから本格利用してください。

## Copilot cloud agent supports auto model selection

**URL:** https://github.blog/changelog/2026-05-14-copilot-cloud-agent-supports-auto-model-selection

### 要約
Copilot cloud agent で Auto モデル選択が使えるようになりました。システム状態やモデル性能に応じて最適なモデルが自動選択され、通常より低いモデル倍率で利用できます。

### ユーザーにとって良いこと
モデル選択の手間が減り、安定した利用がしやすくなります。週次レート制限の影響も受けないため、運用しやすさが上がります。

### アクションプラン
- cloud agent を使うワークフローでは、モデルピッカーを Auto に設定してください。
- コスト最適化を重視するチームは、Auto 選択時の 10% 割引を前提に利用計画を見直してください。

### リファレンス
- [Copilot cloud agent supports auto model selection](https://github.blog/changelog/2026-05-14-copilot-cloud-agent-supports-auto-model-selection)

## Introducing Copilot CLI agent and unified sessions view in GitHub Copilot for JetBrains IDEs

**URL:** https://github.blog/changelog/2026-05-13-introducing-copilot-cli-agent-and-unified-sessions-view-in-github-copilot-for-jetbrains-ides

### 要約
JetBrains IDEs に Copilot CLI agent が public preview で追加され、セッションの一元表示も導入されました。質問ツール、GHES サインイン改善、グローバル `.agent.md`、UI と信頼性の改善も含まれます。

### ユーザーにとって良いこと
IDE からローカル Copilot CLI agent を直接使えて、長時間タスクの進行も見やすくなります。セッション管理と agent 設定が整理され、複数作業の並行運用がしやすくなります。

### アクションプラン
- JetBrains 利用者は最新版プラグインを入れて Copilot CLI agent を試してください。
- 共有エージェント設定が必要なら `~/.copilot/agents/.agent.md` を整備してください。
- ⚠️ Copilot Business / Enterprise では Editor preview features policy の有効化が必要です。Edit mode は廃止済みです。
