## Secret scanning with GitHub MCP Server is now generally available

**URL:** https://github.blog/changelog/2026-05-05-secret-scanning-with-github-mcp-server-is-now-generally-available

### 要約
GitHub MCP Server の secret scanning が一般提供になりました。MCP 対応の AI コーディングエージェントや IDE から、コミット前や PR 作成前に露出したシークレットを検出できます。

### ユーザーにとって良いこと
漏えいした資格情報をリポジトリに入れてしまう前に止められるため、事故対応の手戻りを減らせます。既存の push protection 設定も反映されるので、手元のチェックとリポジトリ側の制御を揃えやすくなります。

### アクションプラン
- GitHub MCP Server を開発環境に設定し、コミット前のシークレット検査を標準手順にしてください。
- リポジトリまたは組織で GitHub Secret Protection を有効化してください。
- GitHub Copilot CLI を使う場合は任意で `/plugin install advanced-security@copilot-plugins` を導入し、必要に応じて `/secret-scanning` を使ってください。

### リファレンス
- [Secret scanning with GitHub MCP Server is now generally available](https://github.blog/changelog/2026-05-05-secret-scanning-with-github-mcp-server-is-now-generally-available)

## Dependency scanning with GitHub MCP Server is in public preview

**URL:** https://github.blog/changelog/2026-05-05-dependency-scanning-with-github-mcp-server-is-in-public-preview

### 要約
GitHub MCP Server の dependabot toolset に、変更中の依存関係の脆弱性スキャンが追加されました。MCP 対応の IDE や AI エージェントから、コミット前に既知の脆弱性と修正版バージョンを確認できます。

### ユーザーにとって良いこと
依存関係の問題を早い段階で見つけられるため、脆弱なパッケージを含んだまま PR を進めるリスクを減らせます。GitHub Advisory Database の結果をそのまま使えるので、修正判断がしやすくなります。

### アクションプラン
- Dependabot alerts を有効にしたリポジトリで、public preview を試してください。
- GitHub Copilot CLI では任意で `copilot --add-github-mcp-toolset dependabot` を有効化してください。
- 依存関係を追加・更新したブランチでは、コミット前に脆弱性スキャンを実行する運用を入れてください。

### リファレンス
- [Dependency scanning with GitHub MCP Server is in public preview](https://github.blog/changelog/2026-05-05-dependency-scanning-with-github-mcp-server-is-in-public-preview)

## Code-to-cloud risk visibility with Microsoft Defender for Cloud is now generally available

**URL:** https://github.blog/changelog/2026-05-05-code-to-cloud-risk-visibility-with-microsoft-defender-for-cloud-is-now-generally-available

### 要約
Microsoft Defender for Cloud との code-to-cloud 連携が一般提供になりました。ビルド成果物とランタイム情報を GitHub Advanced Security の警告やアラートに結びつけ、実行環境まで含めてリスクを見られます。

### ユーザーにとって良いこと
「どのコードが、どこで、どんな状態で動いているか」を踏まえて優先度付けできるため、調査と修正が速くなります。デプロイ状態や runtime-risk で絞り込めるので、実際に露出している問題へ集中しやすくなります。

### アクションプラン
- Microsoft Defender for Cloud の GitHub Advanced Security 連携手順を使って接続してください。
- 必要なら `has:deployment` と `runtime-risk:` フィルタをセキュリティ一覧やキャンペーン作成で使ってください。
- 重要なセキュリティ issue や campaign は GitHub Copilot coding agent に割り当ててください。

### リファレンス
- [Code-to-cloud risk visibility with Microsoft Defender for Cloud is now generally available](https://github.blog/changelog/2026-05-05-code-to-cloud-risk-visibility-with-microsoft-defender-for-cloud-is-now-generally-available)

## Deprecation notice: code_scanning_upload field will be removed from rate_limit API endpoint

**URL:** https://github.blog/changelog/2026-05-05-deprecation-notice-code_scanning_upload-field-will-be-removed-from-rate_limit-api-endpoint

### 要約
`/rate_limit` API の `code_scanning_upload` フィールドが 2026-05-19 に削除されます。実際には `core` と同じレート制限を共有していたため、誤解を招きやすい項目が整理されます。

### ユーザーにとって良いこと
レート制限の表示がより正確になり、誤った残量判断を避けられます。API の意味が単純になるため、運用スクリプトや監視の解釈も合わせやすくなります。

### アクションプラン
- ⚠️ `/rate_limit` を解析して `code_scanning_upload` を参照しているスクリプトやアプリを、2026-05-19 までに修正してください。
- `core` のレート制限だけを参照するように変更してください。代替フィールドは不要です。
- 監視や通知でこの値を使っている場合は、ダッシュボード定義も更新してください。

### リファレンス
- [Deprecation notice: code_scanning_upload field will be removed from rate_limit API endpoint](https://github.blog/changelog/2026-05-05-deprecation-notice-code_scanning_upload-field-will-be-removed-from-rate_limit-api-endpoint)
