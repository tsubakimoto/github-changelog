## Copilot usage metrics API adds cohorts for AI adoption

**URL:** https://github.blog/changelog/2026-05-29-copilot-usage-metrics-api-adds-cohorts-for-ai-adoption

### 要約
Copilot usage metrics API に、ユーザーを AI adoption phase で分類する新しいコホート指標が追加されました。user-level report では `ai_adoption_phase` が、enterprise / organization-level report では `totals_by_ai_adoption_phase` が利用できます。

### ユーザーにとって良いこと
単なるアクティブユーザー数ではなく、Copilot の利用がコード補完中心か、エージェント中心か、複数エージェント活用まで進んでいるかを把握できます。これにより、導入状況の説明、教育施策の優先順位付け、ロールアウト戦略の最適化がしやすくなります。

### アクションプラン
- enterprise admin または organization owner は、Copilot usage metrics REST API の user-level / org-level / enterprise-level report で `ai_adoption_phase` と `totals_by_ai_adoption_phase` を確認してください。
- 既存のダッシュボードや定期レポートに phase 別の指標を追加し、利用成熟度の変化を追跡してください。
- training、ドキュメント、展開計画を phase 別に見直し、移行が遅い層に重点的に支援を当ててください。
- 影響範囲は Copilot usage metrics API を利用する管理者向けです。一般ユーザー向けの UI 変更ではありません。
