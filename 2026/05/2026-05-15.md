## Grok Code Fast 1 deprecated

**URL:** https://github.blog/changelog/2026-05-15-grok-code-fast-1-deprecated

### 要約
Grok Code Fast 1 が Copilot Chat、inline edits、ask/agent モード、コード補完を含むすべての GitHub Copilot 体験で非推奨になりました。代替として GPT-5 mini または Claude Haiku 4.5 が案内されています。

### ユーザーにとって良いこと
サポート対象外モデルを使い続けるリスクを避けられます。代替モデルへ早めに移行することで、Copilot の利用継続性と運用の安定性を保てます。

### アクションプラン
- Copilot のワークフローや統合で Grok Code Fast 1 を使っている場合は、GPT-5 mini か Claude Haiku 4.5 に切り替えてください。
- Copilot Enterprise 管理者は、モデルポリシーで代替モデルへのアクセスが有効か確認してください。
- ⚠️ 非推奨モデルなので、依存箇所は早めに置き換えて運用手順から外してください。

## Copilot Memory supports user preferences for Pro, Pro+ users

**URL:** https://github.blog/changelog/2026-05-15-copilot-memory-supports-user-preferences-for-pro-pro-users

### 要約
Copilot Memory が、Copilot Pro / Pro+ 向けの early access でユーザー単位の好みを保存できるようになりました。これにより、リポジトリをまたいでコミットスタイル、PR の構成、口調などの個人設定を Copilot が引き継げます。

### ユーザーにとって良いこと
作業する場所が変わっても、Copilot が自分の書き方や好みを覚えてくれるようになります。毎回同じ指示を繰り返す手間が減り、出力の一貫性が上がります。

### アクションプラン
- Copilot Pro / Pro+ ユーザーは、個人の Copilot 設定で Copilot Memory を有効にしてください。
- 保存されたユーザー設定は、個人の Copilot Memory 設定画面で確認・削除してください。
- チーム利用では、個人メモリがリポジトリ単位の設定と分かれている点を前提に運用してください。

## Timestamp fields in GitHub Projects

**URL:** https://github.blog/changelog/2026-05-15-timestamp-fields-in-github-projects

### 要約
GitHub Projects に Created、Updated、Closed の 3 つの組み込み timestamp fields が追加されました。各 project view に追加して、作成日、最終更新日、クローズ日時で並び替えや絞り込みができます。

### ユーザーにとって良いこと
「最近追加された作業」「最近更新された作業」「最近完了した作業」を簡単に見える化できます。ダッシュボードやレビュー用ビューを、追加の自動化なしで作りやすくなります。

### アクションプラン
- GitHub Projects の各ビューで、必要な列に Created / Updated / Closed フィールドを追加してください。
- 最近完了した項目や、長く更新されていない項目を追うビューを新しく作ってください。
- Updated は project field の変更でも変わるため、同じ issue でも project ごとに値が異なる点を考慮してください。

- [Timestamp fields in GitHub Projects](https://github.blog/changelog/2026-05-15-timestamp-fields-in-github-projects)
