## Copilot code review: Comment experience improvements

**URL:** https://github.blog/changelog/2026-05-12-copilot-code-review-comment-experience-improvements

### 要約
Copilot code review のコメントが見やすくなり、重要度ラベル、類似コメントのグループ化、改善された suggested changeset UI が追加されました。
大きな PR でも重複やノイズを減らして、Copilot の指摘を優先度順に追いやすくなります。

### ユーザーにとって良いこと
レビューコメントの読み取り負荷が下がり、修正すべき提案をすばやく見分けられます。大きな変更でも、同種の指摘をまとめて把握しやすくなります。

### アクションプラン
- 新しい pull requests 体験を使っているか確認してください。
- Copilot code review の severity ラベルを見て、High から順に対応する運用に切り替えてください。
- グループ化されたコメントの見え方をチーム内で共有してください。

## April reports are now available to prepare for usage-based billing

**URL:** https://github.blog/changelog/2026-05-12-april-reports-are-now-available-to-prepare-for-usage-based-billing

### 要約
4 月の Copilot 利用実績を AI credits に換算したレポートをダウンロードできるようになりました。
6 月 1 日からの usage-based billing に向けて、消費傾向や上位利用者を事前に把握できます。

### ユーザーにとって良いこと
請求開始前にコストの形や利用傾向を見積もれます。Enterprise 管理者は組織単位、Pro/Pro+ 利用者は個人単位で準備できます。

### アクションプラン
- Copilot Business/Enterprise 管理者は企業の April report をダウンロードしてください。
- Copilot Pro/Pro+ 利用者は個人の利用レポートを確認してください。
- 6 月 1 日以降の請求に備え、上位利用者、主なモデル、主な surface を洗い出してください。
- ⚠️ これは再計算済みの請求書ではないため、見積もりとして扱ってください。

## CodeQL 2.25.4 adds Swift 6.3.1 support, improvements to C# and Java, and more

**URL:** https://github.blog/changelog/2026-05-12-codeql-2-25-4-adds-swift-6-3-1-support-improvements-to-c-and-java-and-more

### 要約
CodeQL 2.25.4 で Swift 6.3.1 対応、C# と Java/Kotlin の解析改善、Vercel serverless functions の検出強化が入りました。
さらに、複数言語で data flow barriers を追加できるようになり、カスタム設定で誤検知を抑えやすくなりました。

### ユーザーにとって良いこと
コードスキャンの検出精度とカバレッジが向上します。新しいサニタイザやバリアの理解が増えることで、誤検知を減らしつつ本来見つけたい問題を捉えやすくなります。

### アクションプラン
- GitHub.com の code scanning 利用者は、新しい CodeQL バージョンの自動適用対象を確認してください。
- GHES 利用者は、必要に応じて CodeQL を手動更新してください。
- Swift 6.3.1、Vercel API route、Java の path normalization など、影響があるコードベースで検出結果の変化を確認してください。
- カスタム CodeQL を使っている場合は data extensions / barrier guards の導入を検討してください。

## Synchronous SBOM API deprecated

**URL:** https://github.blog/changelog/2026-05-12-synchronous-sbom-api-deprecated

### 要約
同期版 SBOM API が非推奨になり、新しい非同期 API への移行が必要になりました。
旧エンドポイント `/{owner}/{repo}/dependency-graph/sbom` は 6 か月後の 2026-11-13 に削除予定です。

### ユーザーにとって良いこと
非同期 API は生成完了までのポーリングに変わりますが、パフォーマンスと信頼性が改善されます。SBOM の取得が安定しやすくなります。

### アクションプラン
- ⚠️ `/{owner}/{repo}/dependency-graph/sbom` を使っているスクリプトや統合を `/{owner}/{repo}/dependency-graph/sbom/generate-report` に更新してください。
- 新 API の返す URL をポーリングして完了後にダウンロードする流れへ変更してください。
- 2026-11-13 までに移行を完了してください。

### リファレンス
- [Synchronous SBOM API deprecated](https://github.blog/changelog/2026-05-12-synchronous-sbom-api-deprecated)
