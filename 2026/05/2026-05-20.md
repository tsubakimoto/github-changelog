## Copilot usage metrics reports now use GitHub-owned download URLs

**URL:** https://github.blog/changelog/2026-05-20-copilot-usage-metrics-reports-now-use-github-owned-download-urls

### 要約
Copilot usage metrics report のダウンロード URL が Azure Front Door ベースのドメインから、GitHub 管理の固定ドメインへ移行しました。GHEC では `copilot-reports.github.com`、GHE.com では `copilot-reports.<subdomain>.ghe.com` が使われます。

### ユーザーにとって良いこと
URL がインフラ構成に左右されにくくなり、継続的に使えるリンクになります。企業の firewall や proxy の allowlist 管理もしやすくなります。

### アクションプラン
- `copilot-reports.github.com` または `copilot-reports.<SUBDOMAIN>.ghe.com` を firewall / proxy の allowlist に追加してください。
- 既存の `copilot-reports-*.b01.azurefd.net` 依存の自動化や共有ドキュメントを更新してください。
- ⚠️ 旧ドメインは移行期間のみ有効なので、早めに新しい allowlist へ切り替えてください。
- ⚠️ 必要に応じて `*.blob.core.windows.net` も allowlist に含めてください。

## Updates to available models in Copilot on web

**URL:** https://github.blog/changelog/2026-05-20-updates-to-available-models-in-copilot-on-web

### 要約
Copilot Chat on the web で利用できるモデルの一覧が絞り込まれました。Gemini 系モデルと一部のモデルは削除され、OpenAI と Claude の主要モデルが引き続き利用できます。

### ユーザーにとって良いこと
Web 上の Copilot Chat で、より安定したモデル体験を得やすくなります。推奨モデル中心の構成になり、応答品質のばらつきも減らしやすくなります。

### アクションプラン
- github.com/copilot のモデルピッカーで、必要なモデルが残っているか確認してください。
- Gemini 系や削除されたモデルを前提にした利用手順・社内ドキュメントを更新してください。
- ⚠️ Web 上のモデル選択肢は今後も限定されるため、運用で特定モデル依存を強めすぎないでください。

### リファレンス
- [Updates to available models in Copilot on web](https://github.blog/changelog/2026-05-20-updates-to-available-models-in-copilot-on-web)

## Auto model selection now routes based on your task in VS Code

**URL:** https://github.blog/changelog/2026-05-20-auto-model-selection-now-routes-based-on-your-task-in-vs-code

### 要約
VS Code の Copilot で Auto モードが、タスク内容やモデル健全性に応じて最適なモデルを選ぶようになりました。利用中のモデルはホバーで確認でき、手動で別モデルへ切り替えることもできます。

### ユーザーにとって良いこと
タスクごとに適したモデルへ自動で振り分けられるため、品質とコストのバランスを取りやすくなります。設定変更なしで、軽い作業から難しい推論まで使い分けやすくなります。

### アクションプラン
- VS Code で Copilot のモデル選択を Auto に切り替えて試してください。
- チームの Copilot 利用ガイドに、Auto と手動モデルの使い分け基準を追加してください。
- ⚠️ Auto は選択されたモデルに応じて課金されるため、プレミアムリクエスト消費の見積もりを更新してください。

### リファレンス
- [Auto model selection now routes based on your task in VS Code](https://github.blog/changelog/2026-05-20-auto-model-selection-now-routes-based-on-your-task-in-vs-code)

## Semantic issue search in Copilot Chat

**URL:** https://github.blog/changelog/2026-05-20-semantic-issue-search-in-copilot-chat

### 要約
Copilot Chat on web で、自然言語による semantic issue search が使えるようになりました。単純なキーワード一致だけでなく、意図に近い issue をまとめて探したり分析したりできます。

### ユーザーにとって良いこと
Issue のタイトルや正確なキーワードを覚えていなくても、目的に近い課題を見つけやすくなります。トリアージや計画立案の初動を速められます。

### アクションプラン
- Copilot Chat on web で、issue の検索・分類・分析に自然言語クエリを使ってみてください。
- Issue トリアージの手順書に、semantic search を使った探し方を追加してください。
- GitHub 側の追加設定は不要なので、利用ルールだけチームで揃えてください。

### リファレンス
- [Semantic issue search in Copilot Chat](https://github.blog/changelog/2026-05-20-semantic-issue-search-in-copilot-chat)
