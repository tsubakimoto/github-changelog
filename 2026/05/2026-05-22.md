## Staged publishing and new install-time controls for npm

**URL:** https://github.blog/changelog/2026-05-22-staged-publishing-and-new-install-time-controls-for-npm

### 要約
npm で供給網セキュリティを強化する 2 つの更新が一般提供されました。1 つは `npm stage publish` による staged publishing の GA、もう 1 つは `--allow-file`、`--allow-remote`、`--allow-directory` の新しい install source 制御です。いずれも npm CLI 11.15.0 以降で利用できます。

### ユーザーにとって良いこと
公開前に人の承認を挟めるため、CI/CD からの誤公開や不正公開のリスクを下げやすくなります。あわせて、Git・ファイル・URL・ディレクトリ由来の依存関係を明示的に制御でき、依存取得の安全性と可観測性が上がります。

### アクションプラン
- npm CLI を 11.15.0 以上に更新し、staged publishing を使うパッケージでは CI の `npm publish` を `npm stage publish` に置き換えてください。
- trusted publishing（OIDC）を使っている workflow は、stage-only で許可する設定に切り替え、誤って通常 publish しないようにしてください。
- `.npmrc` / `package.json` の install source 設定で `--allow-file`、`--allow-remote`、`--allow-directory`、`--allow-git` の許可範囲を見直してください。
- ⚠️ `--allow-git` は次の major で既定が `all` から `none` に変わる予定なので、依存取得に Git source を使う箇所は先に洗い出してください。
