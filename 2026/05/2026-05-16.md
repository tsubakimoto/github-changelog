## GitHub App installation tokens: Per-request override header

**URL:** https://github.blog/changelog/2026-05-15-github-app-installation-tokens-per-request-override-header

### 要約
GitHub App installation token の新しい stateless 形式への移行に向けて、リクエスト単位でトークン形式を強制できる一時的なヘッダーが追加されました。`X-GitHub-Stateless-S2S-Token` を使うと、単一の `POST /app/installations/:installation_id/access_tokens` リクエストで新旧どちらの形式を返すかを制御できます。

### ユーザーにとって良いこと
ロールアウト前に新しい JWT 形式のトークンを本番相当で検証できるため、移行時の障害を減らせます。逆に、まだ準備できていない場合は旧形式を維持して、段階的に対応を進められます。

### アクションプラン
- `POST /app/installations/:installation_id/access_tokens` を呼ぶ実装に `X-GitHub-Stateless-S2S-Token: enabled` を付け、stateless token を受け取れるか確認してください。
- token 長さ、正規表現、DB カラム長を見直し、`ghs_` で始まる約 520 文字の JWT を受け入れられるようにしてください。
- 互換性確認のため `disabled` でも同じ処理が動くことをテストし、検証が終わったら本番コードからこの一時ヘッダーを削除してください。
