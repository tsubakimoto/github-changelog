## One-click fixes for failing Actions with Copilot cloud agent

**URL:** https://github.blog/changelog/2026-05-18-one-click-fixes-for-failing-actions-with-copilot-cloud-agent

### 要約
GitHub Actions の失敗ジョブを、Copilot Business / Enterprise であればワンクリックで Copilot cloud agent に修復依頼できるようになりました。cloud agent は失敗原因を調べ、修正をブランチに push して、レビュー依頼まで行います。

### ユーザーにとって良いこと
テスト失敗や lint エラーのような定型的な修正を、手作業で切り分ける時間を減らして任せられます。CI の復旧速度が上がり、開発者は本来の実装に集中しやすくなります。

### アクションプラン
- Actions の失敗後に `Fix with Copilot` を使う運用をチームに周知してください。
- 組織で Copilot cloud agent が有効か、管理者設定を確認してください。
- ⚠️ 自動修正がそのままマージされないよう、レビュー手順を明確にしてください。

### リファレンス
- [One-click fixes for failing Actions with Copilot cloud agent](https://github.blog/changelog/2026-05-18-one-click-fixes-for-failing-actions-with-copilot-cloud-agent)

## Copilot cloud agent: Fast, cost-efficient models for simple tasks

**URL:** https://github.blog/changelog/2026-05-18-copilot-cloud-agent-fast-cost-efficient-models-for-simple-tasks

### 要約
Copilot cloud agent で使えるモデルに、Claude Haiku 4.5 と GPT-5.4-mini が追加されました。より軽い変更には高速・低コストなモデル、難しい作業には従来のモデルを選べるようになりました。

### ユーザーにとって良いこと
用途に応じてコストと速度を調整できるため、日常的な小規模修正の待ち時間や利用コストを下げやすくなります。より重いタスクにだけ高性能モデルを使う運用もしやすくなります。

### アクションプラン
- cloud agent の既定モデルと使い分けルールを決めてください。
- 小さな修正タスクに対して低コストモデルを試し、実行時間と成果を比較してください。
- モデル選択を運用手順に反映し、メンバーが迷わないようにしてください。

### リファレンス
- [Copilot cloud agent: Fast, cost-efficient models for simple tasks](https://github.blog/changelog/2026-05-18-copilot-cloud-agent-fast-cost-efficient-models-for-simple-tasks)

## Ask questions in context with Copilot on web

**URL:** https://github.blog/changelog/2026-05-18-ask-questions-in-context-with-copilot-on-web

### 要約
Copilot chat on the web が、閲覧中の GitHub ページ上でパネルとして開くようになりました。Pull request や issue を見ながらそのまま質問でき、複数の画面をまたいで文脈を維持しやすくなっています。

画面遷移が減るので、レビューや調査の流れを中断しにくくなります。PR や issue を見ながら質問を続けられるため、必要な情報収集が速くなります。

### アクションプラン

- PR / issue 画面での質問例をまとめ、定常的な使い方を決めてください。
- 必要に応じて immersive chat への切り替え手順も案内してください。

## Audit repository Copilot cloud agent configuration via the REST API

**URL:** https://github.blog/changelog/2026-05-18-audit-repository-copilot-cloud-agent-configuration-via-the-rest-api

### 要約
新しい REST API で、リポジトリごとの Copilot cloud agent 設定を監査できるようになりました。MCP サーバー設定、利用可能なツール、GitHub Actions のポリシー、ファイアウォール設定などを取得できます。

### ユーザーにとって良いこと
複数リポジトリの設定を手動で確認する負担を減らし、セキュリティ状態を横断的に把握しやすくなります。運用ルール違反や設定漏れの検出も自動化しやすくなります。

### アクションプラン
- 監査対象リポジトリの一覧から、この API を定期実行する仕組みを作ってください。
- 取得結果をもとに、許可ツールや Actions ポリシーの差分を洗い出してください。
- ⚠️ 公開プレビューのため、本番運用では失敗時の扱いと代替手順を決めてください。

### リファレンス
- [Audit repository Copilot cloud agent configuration via the REST API](https://github.blog/changelog/2026-05-18-audit-repository-copilot-cloud-agent-configuration-via-the-rest-api)

- Spaces の作成・更新・削除を行う内部ツールやスクリプトを整備してください。

## Remote control for Copilot CLI sessions now generally available on mobile, web, and VS Code

**URL:** https://github.blog/changelog/2026-05-18-remote-control-for-copilot-cli-sessions-now-generally-available-on-mobile-web-and-vs-code

### 要約
Copilot CLI セッションの remote control が、GitHub Mobile と github.com で一般提供され、VS Code と JetBrains からも使えるようになりました。非 GitHub リポジトリや repository に紐づかないディレクトリにも対応し、外出先からセッションを監視・操作できます。

### ユーザーにとって良いこと
端末の前にいなくても進行中の CLI セッションを確認し、必要に応じて指示を追加できます。長時間の作業を中断しにくくなり、作業の継続性が上がります。

### アクションプラン
- `copilot --remote` と `/remote on` の社内手順を整備してください。
- VS Code / JetBrains / Mobile での利用方法をチームに案内してください。
- ⚠️ 権限リクエストやセッション操作の扱いを決め、誤操作時の対応を明文化してください。

### リファレンス
- [Remote control for Copilot CLI sessions now generally available on mobile, web, and VS Code](https://github.blog/changelog/2026-05-18-remote-control-for-copilot-cli-sessions-now-generally-available-on-mobile-web-and-vs-code)

## GPT-5.3-Codex is now the base model for Copilot Business and Enterprise

**URL:** https://github.blog/changelog/2026-05-17-gpt-5-3-codex-is-now-the-base-model-for-copilot-business-and-enterprise

### 要約
Copilot Business と Enterprise の既定モデルが GPT-5.3-Codex に切り替わりました。これは 12 か月保証の LTS モデルで、承認済みでないモデルを使う場合のベースラインとして動作します。

### ユーザーにとって良いこと
企業向けに安定した既定モデルが提供されるため、セキュリティ審査や社内承認の運用がしやすくなります。既定モデルの長期利用前提が明確になることで、管理の予測可能性も上がります。

### アクションプラン
- Copilot Business / Enterprise のモデル管理方針を GPT-5.3-Codex 前提で見直してください。
- まだ旧既定モデルに依存する運用があれば、置き換え計画を立ててください。
- ⚠️ 2026-06-01 の usage-based billing 開始に備え、請求影響を確認してください。

### リファレンス
- [GPT-5.3-Codex is now the base model for Copilot Business and Enterprise](https://github.blog/changelog/2026-05-17-gpt-5-3-codex-is-now-the-base-model-for-copilot-business-and-enterprise)
