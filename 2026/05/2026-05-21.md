## GitHub Copilot for Eclipse is open source

**URL:** https://github.blog/changelog/2026-05-21-github-copilot-for-eclipse-is-open-source

### 要約
GitHub Copilot for Eclipse のコードが MIT ライセンスで公開され、実装を GitHub 上で確認できるようになりました。チャット、補完、Agent mode、Skills、BYOK、MCP 連携など、主要な仕組みも含めて参照できます。

### ユーザーにとって良いこと
動作の透明性が高まり、Eclipse 向け Copilot の作りを学んだり、改善提案や貢献をしやすくなります。チームは独自の拡張や運用方針を、公開実装に沿って検討しやすくなります。

### アクションプラン
- Eclipse 向け Copilot を使っている場合は、公開された実装と社内の拡張や運用差分を確認してください。
- 不具合修正や改善案があれば、GitHub 上のリポジトリに issue / pull request でフィードバックしてください。
- ⚠️ 既存の非公開フォークや独自パッチがある場合は、公開コードとの差分とライセンス条件を再確認してください。

## Issue fields are now in public preview for all organizations

**URL:** https://github.blog/changelog/2026-05-21-issue-fields-are-now-in-public-preview-for-all-organizations

### 要約
Issue fields が、github.com と data residency 対応の GitHub Enterprise Cloud 上で、すべての organization に public preview として提供されました。Priority や Effort のような typed metadata を organization 単位で定義でき、全リポジトリの issue に自動で適用できます。

### ユーザーにとって良いこと
ラベルに頼りすぎず、検索・フィルタ・自動化に使える構造化データを共通化できます。issue 作成から project 管理まで一貫したメタデータ運用にしやすくなります。

### アクションプラン
- Organization の `Settings > Planning > Issue fields` で public preview を試し、標準化したい項目を定義してください。
- 既存の label ベース運用を、issue fields と project columns に置き換えられるか確認してください。
- REST / GraphQL / webhook を使う自動化がある場合は、field 値の読み書きに対応するよう更新してください。
- ⚠️ Public preview のため、運用ルールと可視性設定を先に決めてから全社展開してください。
