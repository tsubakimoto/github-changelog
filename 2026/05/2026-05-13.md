## New enterprise installation API now in public preview

**URL:** https://github.blog/changelog/2026-05-13-new-enterprise-installation-api-now-in-public-preview

### 要約
GitHub App 向けに、Enterprise にインストール済みかどうかと installation ID を取得する新しい API が public preview で追加されました。既存の organization / repository / user 向け API と同じ流れで、対象 installation の特定がしやすくなります。

### ユーザーにとって良いこと
Enterprise 対象の installation token を、一覧走査やページネーションなしで素早く取得できます。GitHub App の認証フローや自動化の待ち時間を減らせます。

### アクションプラン
- GitHub App で Enterprise 対応が必要なら、REST API ドキュメントを確認して新 API を試してください。
- installation ID を探すための列挙処理があれば、この API に置き換えてください。
- ⚠️ public preview なので、本番適用前にエラー処理と後方互換性を確認してください。

### リファレンス
- [New enterprise installation API now in public preview](https://github.blog/changelog/2026-05-13-new-enterprise-installation-api-now-in-public-preview)

## Start Copilot cloud agent tasks via the REST API

**URL:** https://github.blog/changelog/2026-05-13-start-copilot-cloud-agent-tasks-via-the-rest-api

### 要約
Copilot cloud agent のタスクを REST API から起動できる public preview が追加されました。タスクの進行状況も API で追跡でき、複数リポジトリへの自動化や新規リポジトリの初期化に使えます。

### ユーザーにとって良いこと
Copilot cloud agent を社内ツールや運用自動化に組み込みやすくなります。リファクタリング、セットアップ、定期作業の実行をスクリプトからまとめて扱えます。

### アクションプラン
- Copilot Business / Enterprise で、自動化フローに Agent tasks REST API を組み込んでください。
- 既存の手動タスク起動を、API ベースの処理に置き換えられるか確認してください。
- ⚠️ 認証は PAT と OAuth のみ対応です。GitHub App token と Copilot Pro / Pro+ 対応は未提供なので前提にしないでください。

### リファレンス

## GitHub Enterprise Server 3.21 release candidate is available

**URL:** https://github.blog/changelog/2026-05-13-github-enterprise-server-3-21-release-candidate-is-available

### 要約
GHES 3.21 の release candidate が公開されました。権限管理、Projects の階層表示、Actions の大規模ワークフロー表示、REST API の新バージョン、secret scanning、データディスク構成などに改善があります。

### ユーザーにとって良いこと
管理機能と可視化が強化され、Enterprise 運用や大規模ワークフローの扱いやすさが上がります。API や secret scanning の更新で、ガバナンスと保守性も改善します。

### アクションプラン
- GHES 3.21 を評価する環境で、release candidate を検証してください。
- REST API version 2026-03-10 の破壊的変更を確認し、既存連携の影響を洗い出してください。
- GitHub Actions の大規模ワークフローや secret scanning の管理フローを使っている場合は、UI と権限の変化を確認してください。
- ⚠️ release candidate なので、本番導入前にアップグレード手順とロールバック手順を確認してください。
