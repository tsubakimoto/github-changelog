重要アップデート（ピックアップ）

  • Upcoming deprecation of GPT-5.2 and GPT-5.2-Codex - 6/1に向けたモデル切替が必要で、Copilot運用と管理ポリシーへの影響が大きい変更です。
  • Removal of code_scanning_upload field from rate_limit API endpoint - APIレスポンス互換性に関わる削除で、既存クライアント実装の見直し対象です。
  • Synchronous SBOM API deprecated - SBOM連携で非推奨API移行が必要になり、セキュリティ運用の更新計画が求められます。
  • Copilot Spaces API now generally available - 生成AI活用の中核APIがGA化し、本番利用しやすくなりました。
  • Gemini 3.5 Flash is generally available for GitHub Copilot - 利用可能モデルの選択肢拡大により、コスト/速度最適化の幅が広がります。
  • Hard budget limits now available for GitHub Advanced Security - 予算の上限制御を強化でき、セキュリティ機能のコスト管理を厳格化できます。
  • GitHub Actions: Upcoming image migrations - ランナー環境変更に備え、ワークフローの互換性確認が必要です。
  • Staged publishing and new install-time controls for npm - npm配布フローと導入時制御が強化され、サプライチェーン運用に直接効く更新です。
