## Hard budget limits now available for GitHub Advanced Security

**URL:** https://github.blog/changelog/2026-05-28-hard-budget-limits-now-available-for-github-advanced-security

### 要約
GitHub Advanced Security のライセンス利用に、上限到達後の追加割り当てを止めるハードバジェットが追加されました。従来のソフトバジェット通知に加えて、予算超過を実際に防げるようになります。コストセンターや組織単位での制御もでき、現在の利用量に応じた下限も自動で考慮されます。

### ユーザーにとって良いこと
セキュリティ機能の利用拡大時に、意図しない課金増加を防げます。予算残量が見えやすくなり、運用担当者はライセンス管理をより厳密に行えます。

### アクションプラン
- GHAS を使っている企業は、既存の Budgets & alerts 設定を確認し、ソフト予算をハード予算へ移行してください。
- IdP グループ自動割り当てを使っている場合は、上限到達時に新規ユーザーが止まる影響を確認してください。
- コストセンター配賦を使う組織は、組織ごとのライセンス上限を見直してください。⚠️ 上限到達後は新しい GHAS 割り当てがブロックされます。

## CodeQL 2.25.5 improves query accuracy for GitHub Actions

**URL:** https://github.blog/changelog/2026-05-28-codeql-2-25-5-improves-query-accuracy-for-github-actions

### 要約
CodeQL 2.25.5 で、C/C++、Java/Kotlin、GitHub Actions 向けのクエリ精度が改善されました。特に GitHub Actions では composite action のメタデータも解析対象に入り、未固定タグや untrusted checkout 系の検出がより広く、より正確になります。あわせて一部の false positive も削減されています。

### ユーザーにとって良いこと
コードスキャンのノイズが減り、本当に対処すべき警告に集中しやすくなります。GitHub Actions の composite action までカバーされるため、見逃しも減ります。

### アクションプラン
- GitHub Enterprise Server を使っている場合は、CodeQL のバージョンを 2.25.5 以降に更新できるか確認してください。
- 既存の code scanning アラートは、今回の精度改善後に再トリアージしてください。
- GitHub Actions の composite action を使っているリポジトリでは、未固定参照の有無を追加で確認してください。

### リファレンス
- [CodeQL 2.25.5 improves query accuracy for GitHub Actions](https://github.blog/changelog/2026-05-28-codeql-2-25-5-improves-query-accuracy-for-github-actions)

## Claude Opus 4.8 is generally available for GitHub Copilot

**URL:** https://github.blog/changelog/2026-05-28-claude-opus-4-8-is-generally-available-for-github-copilot

### 要約
Claude Opus 4.8 が GitHub Copilot で一般提供され、VS Code、Copilot CLI、cloud agent など多くの面で選択できるようになりました。コード理解や大規模コードベースの移動性能が向上しており、段階的に展開されます。利用には Copilot Pro+、Business、Enterprise の対象プランが必要です。

### ユーザーにとって良いこと
より複雑な実装や大きなリポジトリの作業で、Copilot の応答品質が上がります。日常的なチャット、編集、エージェント作業の精度向上が期待できます。

### アクションプラン
- Copilot Business / Enterprise の管理者は、Copilot 設定で Claude Opus 4.8 ポリシーを有効にしてください。
- 利用者には、モデルピッカーでの選択方法を案内してください。
- 15X の premium request multiplier があるため、Usage Based Billing 開始前の利用量を確認してください。⚠️ 2026-06-01 まではプレミアム消費が大きくなります。
