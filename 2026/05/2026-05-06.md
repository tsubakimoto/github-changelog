## Enterprise-managed plugins in GitHub Copilot CLI are now in public preview

**URL:** https://github.blog/changelog/2026-05-06-enterprise-managed-plugins-in-github-copilot-cli-are-now-in-public-preview

### 要約
Enterprise 管理者が、Copilot CLI のプラグインを組織全体に配布・標準化できるようになりました。自動インストールや常時有効な hooks / MCP 設定も含めて、利用環境を中央集約で統制できます。

### ユーザーにとって良いこと
新しい Copilot CLI の初期設定を各開発者が個別に行う必要が減り、オンボーディングが速くなります。企業としては、カスタムエージェントやスキルを広く展開しながら、ガバナンスも維持しやすくなります。

### アクションプラン
- Enterprise 管理者は `.github-private/.github/copilot/settings.json` にプラグイン設定を追加してください。
- Copilot Business / Enterprise ライセンスの利用者に対して、自動適用される設定内容を確認してください。
- 既存の source organization 設定がある場合は、同じ `.github-private` リポジトリで整合しているか確認してください。
- ⚠️ 企業標準として配布されるため、意図しない拡張が含まれないよう配布前にレビューしてください。

## GitHub Copilot in Visual Studio Code, April releases

**URL:** https://github.blog/changelog/2026-05-06-github-copilot-in-visual-studio-code-april-releases

### 要約
VS Code の Copilot では、意味検索、履歴検索、トークン節約の改善、エージェント向けの操作性向上がまとまって追加されました。Copilot CLI セッションのリモート監視や、終端の操作、ブラウザー共有など、長時間のエージェント作業を支える機能も拡充されています。

### ユーザーにとって良いこと
コード探索や過去作業の再利用がしやすくなり、同じ情報を何度も説明する手間が減ります。エージェントの可視性が上がるので、長いタスクでも中断しにくく、チームでの利用にも向きます。

### アクションプラン
- `github.copilot.chat.localIndex.enabled` を有効化して、意味検索の利用可否を確認してください。
- /chronicle を試して、過去セッションの検索が自分の作業に役立つか評価してください。
- チームで Copilot を使う場合は、BYOK やドメイン制御の管理ポリシーを確認してください。
- ⚠️ experimental 機能は本番運用前に対象ユーザーを絞って検証してください。

## Search and filter bar for repository security advisories

**URL:** https://github.blog/changelog/2026-05-06-search-and-filter-bar-for-repository-security-advisories

### 要約
リポジトリの Security タブで、セキュリティアドバイザリをキーワードや属性で直接検索・絞り込みできるようになりました。API やページ移動に頼らず、対象の脆弱性を素早く見つけられます。

### ユーザーにとって良いこと
脆弱性対応の初動が速くなり、調査やトリアージの時間を短縮できます。確認したい advisory にすぐ到達できるため、セキュリティ運用の負担が下がります。

### アクションプラン
- Security タブで新しい検索バーとフィルターを使い、既存の運用に合うか確認してください。
- 影響の大きい package / ecosystem / severity を基準に、チームの確認手順を見直してください。
- API ベースの作業が多い場合でも、まず UI で素早く絞り込めるか試してください。
