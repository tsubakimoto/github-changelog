## AI credit pools for cost centers in the billing UI

**URL:** https://github.blog/changelog/2026-07-20-ai-credit-pools-for-cost-centers-in-the-billing-ui

### 要約
Cost center の AI credit pool を、REST API ではなく billing UI から作成・編集できるようになりました。pool の上限は割り当て済み Copilot ライセンス数から自動計算され、手動で数値を入力する必要はありません。上限到達時の動作は、included usage を止めるか、契約上許可されていれば追加課金として継続するかを選べます。

### ユーザーにとって良いこと
コスト管理の設定を UI で完結できるため、運用が簡単になります。ライセンス数に連動して上限が自動調整されるので、割り当てと実際の利用状況のズレも抑えやすくなります。

### アクションプラン
- Copilot Business / Enterprise on GitHub Enterprise Cloud を使っている管理者は、cost center の AI credit pool を billing UI で設定する運用に切り替えてください。これは **管理 UI の追加** です。
- 既存の cost center を確認し、上限到達時に **block further included usage** にするか **overages を許可する** かを明確に決めてください。
- REST API でのみ管理していた手順があれば、UI ベースの手順書に更新してください。

## GitHub Code Quality is now generally available

**URL:** https://github.blog/changelog/2026-07-20-github-code-quality-is-now-generally-available

### 要約
GitHub Code Quality が GitHub Enterprise Cloud と GitHub Team で一般提供になりました。CodeQL の deterministic analysis と AI-assisted detection を組み合わせ、PR 上で maintainability / reliability の問題を検出し、Copilot Autofix で修正候補も出せます。organization-wide enablement、Cobertura XML のカバレッジ表示、rulesets による quality gate、API も追加されています。

### ユーザーにとって良いこと
コードの品質問題を PR の段階で見つけやすくなり、修正も提案まで含めて進めやすくなります。カバレッジや quality gate を合わせることで、レビュー前後の品質基準を組織で揃えやすくなります。

### アクションプラン
- Code Quality を使う予定がある organization は、まず有効化対象の repository を決めてください。これは **有料の個別製品を有効化する変更** です。
- 既存のテストレポートがある場合は、Cobertura XML を PR に出せるように整備してください。
- rulesets の quality gate で coverage threshold を設定し、段階的に evaluate mode から展開してください。
- すでに public preview を使っている場合は、July 20, 2026 以降の課金開始を前提に、不要な repository での有効化を見直してください。
