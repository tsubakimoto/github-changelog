## Improvements to secret scanning and public monitoring

**URL:** https://github.blog/changelog/2026-07-15-improvements-to-secret-scanning-and-public-monitoring

### 要約
GitHub の secret scanning に Resend の新しいパートナー対応が追加され、APIclub と Resend の新しいシークレット種別が検出対象になりました。あわせて、VolcEngine のシークレットは push protection の既定対象に拡張され、`secret_scanning_alert` webhook には `secret_category` が追加されています。public monitoring のアラート一覧には、属性別の漏えい数や enterprise メンバー数、verified domains を示す insight cards も表示されます。

### ユーザーにとって良いこと
検出精度と自動保護が強化され、漏えいした認証情報をより早く止めやすくなります。Webhook とダッシュボードの情報が増えることで、アラートの分類、対応優先度付け、レポート作成がしやすくなります。

### アクションプラン
- `secret_scanning_alert` webhook を購読している場合は `secret_category` を利用し、`default` と `generic` を分けてルーティングしてください。
- push protection を使っているリポジトリでは、VolcEngine トークンのブロックが既定で有効になる前提で運用手順を確認してください。
- Resend または APIclub のトークンを扱う組織は、検出通知先と自動失効フローを見直してください。
- public monitoring を運用している enterprise は、insight cards の指標を定例レビューに組み込み、漏えい源の傾向を継続監視してください。

## GitHub Copilot in Visual Studio — June update

**URL:** https://github.blog/changelog/2026-07-14-github-copilot-in-visual-studio-june-update

### 要約
Visual Studio の Copilot では、使用量の可視化とアラート、MCP サーバー更新時の信頼確認、C++ modernization agent の一般提供などが追加されました。さらに、長距離の next edit suggestions、Pull Request の Copilot Chat 連携、IDE 内での PR レビュー操作にも対応しています。

### ユーザーにとって良いこと
Copilot の利用状況と課金境界が見えやすくなり、予期しない超過を防ぎやすくなります。MCP サーバーの変更検知や IDE 内 PR レビューにより、開発フローの安全性と速度が上がります。

### アクションプラン
- Visual Studio 利用者は Copilot Usage ウィンドウのしきい値を見直し、通知が早すぎる/遅すぎる場合は調整してください。
- MCP サーバーを使うチームは、更新後に trust dialog が出る運用を前提に、承認フローを整備してください。
- C++ の更新案件がある場合は、Modernize の Automated/Guided モードをどちらで使うかを決めて展開してください。
- PR レビューを IDE に寄せたい場合は、Preview Features と必要権限を有効化し、レビュー手順を Visual Studio ベースに統一してください。
