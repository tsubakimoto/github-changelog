## New Copilot usage metrics impact dashboard

**URL:** https://github.blog/changelog/2026-07-22-new-copilot-usage-metrics-impact-dashboard

### 要約
Enterprise 管理者と organization owner 向けに、Copilot の利用状況を「誰が使っているか」だけでなく「どう使っているか」まで見える新しい impact dashboard が追加されました。AI adoption phase ごとの cohort を可視化し、深い利用段階への移行を促す指標や次のアクションも確認できます。

### ユーザーにとって良いこと
Copilot の定着状況をより実態に近く把握でき、単純なアクティブ人数以上の投資対効果を説明しやすくなります。未活用のライセンスを見つけて、Enablement の優先順位付けもしやすくなります。

### アクションプラン
- Enterprise 管理者または organization owner は、Copilot usage metrics へのアクセス権を確認してください。
- `ai_adoption_phase` の cohort を見て、Passive ユーザー向けのオンボーディング施策を実施してください。
- 週次または月次でダッシュボードを確認し、Phase 2 / Phase 3 への移行率を追跡してください。

## Upcoming GHES change impacting uploading support bundles

**URL:** https://github.blog/changelog/2026-07-22-upcoming-ghes-change-impacting-uploading-support-bundles

### 要約
2026-08-18 以降、古い GHES からのコマンドラインによる support bundle アップロードが、必要なセキュリティパッチ未適用の場合に拒否されるようになります。対象コマンドは `ghe-support-bundle`、`ghe-cluster-support-bundle`、`ghe-support-upload` です。

### ユーザーにとって良いこと
サポート bundle の送信経路が強化され、より安全な運用につながります。あわせて、必要な更新作業が明確になるため、サポート対応時の予期せぬ失敗を減らせます。

### アクションプラン
- ⚠️ 2026-08-18 までに、現在のバージョンラインで利用可能な最新パッチへ GHES を更新してください。
- 対象の最小パッチバージョン（3.21.3 / 3.20.5 / 3.19.9 / 3.18.12 / 3.17.18）を確認し、運用台帳に反映してください。
- サポート bundle の提出手順を使っているチームは、更新完了までの代替連絡手段を GitHub Support と確認してください。
