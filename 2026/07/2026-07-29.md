## Copilot code review: Agent skills and MCP now generally available

**URL:** https://github.blog/changelog/2026-07-29-copilot-code-review-agent-skills-and-mcp-now-generally-available

### 要約
Copilot code review で agent skills と MCP サーバーの利用が一般提供になりました。これにより、レビュー時にリポジトリ固有の手順や外部システムの文脈を取り込めます。コメントには skills や MCP が使われたことも明示されるため、どの情報で指摘されたか追跡しやすくなっています。

### ユーザーにとって良いこと
コードレビューが、チームの標準や社内ツールを踏まえた、より実運用に近い内容になります。既存の public preview 設定はそのまま使えるので、移行コストも低めです。

### アクションプラン
- public preview で既に設定済みなら、追加作業なしで継続利用する。
- 新規導入する場合は、リポジトリ設定で MCP サーバーを登録し、必要なトークンを Secrets and variables の Agents に保存する。
- リポジトリごとのレビュー手順を反映したい場合は、`.github/skills/<skill>/SKILL.md` を追加する。
- MCP は read-only のみなので、レビューで参照したい外部データを絞り込んで接続する。

## Default model enablement for Copilot Business and Enterprise

**URL:** https://github.blog/changelog/2026-07-29-default-model-enablement-for-copilot-business-and-enterprise

### 要約
Copilot Business と Enterprise で、一般提供されたモデルを既定で有効化する新しいポリシーが追加されました。今後 28 日は設定可能ですが、8 月 26 日から実際に反映されます。未設定のモデルは「inherits default」に切り替わり、組織のポリシーに追従します。

### ユーザーにとって良いこと
新しいモデルが出るたびに管理者が手動で有効化しなくても、利用可能な状態を保ちやすくなります。組織としては、明示的な許可・禁止を残しつつ、運用負荷を下げられます。

### アクションプラン
- ⚠️ 8 月 26 日までに、enterprise / organization の model settings を確認する。
- 既定で新モデルを使わせたくない場合は、policy を disabled に設定する。
- すでに明示的に有効/無効にしているモデルは維持されるため、例外設定を棚卸しする。
- Open-weight モデルやデータ保持契約外のモデルは対象外なので、別扱いで確認する。

## CodeQL 2.26.1 improves analysis accuracy and framework coverage

**URL:** https://github.blog/changelog/2026-07-29-codeql-2-26-1-improves-analysis-accuracy-and-framework-coverage

### 要約
CodeQL 2.26.1 で、Go、Java/Kotlin、JavaScript/TypeScript のフレームワーク対応が広がり、Rust の false positive も減りました。特に `log/slog`、Apache POI、Angular の `HostListener` まわりで分析精度が向上しています。既存のクエリ挙動も一部更新され、検出範囲やノイズが変わる可能性があります。

### ユーザーにとって良いこと
コードスキャンの結果がより実態に近づき、見逃しと誤検知の両方が減りやすくなります。新しい脆弱性検出の対象が増える一方で、既存アラートの再評価も進めやすくなります。

### アクションプラン
- GitHub.com 利用者は自動適用されるため、コードスキャン結果の変化を確認する。
- GHES を使っている場合は、必要に応じて CodeQL の手動アップグレードを計画する。
- `go/log-injection`、`go/clear-text-logging`、`java/path-injection`、`java/ssrf`、`js/missing-origin-check`、`rust/hard-coded-cryptographic-value` の新しい挙動を前提に、既存の抑制設定を見直す。
