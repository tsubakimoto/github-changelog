## Repository-level GitHub Copilot usage metrics generally available

**URL:** https://github.blog/changelog/2026-07-17-repository-level-github-copilot-usage-metrics-generally-available

### 要約
Copilot usage metrics API に、リポジトリ単位の 1 日レポートが追加されました。enterprise と organization の両方で、Copilot coding agent の PR 作成・マージ数と、Copilot code review のレビュー数とコメント内訳を取得できます。

### ユーザーにとって良いこと
組織全体だけでなく、どのリポジトリで Copilot が実際に使われているかを追えるようになります。導入効果の高いリポジトリを見つけて、AI 活用の展開先を絞り込みやすくなります。

### アクションプラン
- enterprise または organization の Copilot metrics レポート取得処理に、`/reports/repos-1-day` を追加してください。
- 対象リポジトリごとの PR 生成・レビュー件数を定例レポートに載せ、導入効果の高い領域を特定してください。
- ⚠️ `Copilot usage metrics policy` を有効化し、`View Copilot Metrics` 権限を持つ担当者だけが参照できる運用にしてください。

## GitHub Copilot app now available in the usage metrics API

**URL:** https://github.blog/changelog/2026-07-17-github-copilot-app-now-available-in-the-usage-metrics-api

### 要約
usage metrics API に GitHub Copilot app の利用状況が追加されました。1 日・28 日レポートで、アクティブユーザー数、セッション数、リクエスト数、プロンプト数、トークン消費を確認できます。

### ユーザーにとって良いこと
IDE や chat だけでなく、Copilot app の利用実態も同じ API で追跡できるようになります。利用浸透やコスト傾向をまとめて見られるため、導入状況の把握がしやすくなります。

### アクションプラン
- enterprise / organization の既存メトリクス収集に `daily_active_copilot_app_users` と `totals_by_copilot_app` を追加してください。
- Copilot app の利用がない組織では `null` が返る前提で、既存ダッシュボードの欠損処理を確認してください。
- Copilot app の利用状況を、IDE・code review・coding agent の指標と並べて定例確認してください。

## Copilot code review: Customization and configurability improvements

**URL:** https://github.blog/changelog/2026-07-17-copilot-code-review-customization-and-configurability-improvements

### 要約
Copilot code review のカスタマイズ性が大きく拡張されました。ヘッドブランチ上の instructions を読み込むようになり、`REVIEW.md` / `GEMINI.md` / `CLAUDE.md` にも対応し、`.github/workflows/copilot-code-review.yml` で実行環境やセットアップ手順を定義できます。さらに firewall が既定で有効化され、organization 側では runner 設定が cloud agent と code review で分離されました。

### ユーザーにとって良いこと
PR ごとに実験的な指示を試しやすくなり、レビュー品質を改善しやすくなります。環境構築やネットワーク制御も個別に調整できるため、実運用に合わせたレビュー自動化へ寄せやすくなります。

### アクションプラン
- custom instructions を試す場合は、ベースブランチではなく head branch に `copilot-instructions.md` や `*.instructions.md` を置いて検証してください。
- リポジトリ単位でレビュー環境を整えたい場合は、`.github/workflows/copilot-code-review.yml` を追加して依存関係インストールや runner 設定を定義してください。
- ⚠️ firewall が既定で有効なので、外部ネットワーク前提のレビューは許可先を見直してください。
- ⚠️ self-hosted runners は firewall 非対応のため、該当環境では従来どおりの挙動になる点を運用に反映してください。

## GitHub Mobile: Fix pull request comments with Copilot cloud agent

**URL:** https://github.blog/changelog/2026-07-17-github-mobile-fix-pull-request-comments-with-copilot-cloud-agent

### 要約
GitHub Mobile から、PR コメントの `Fix with Copilot` を直接起動できるようになりました。PR のメイン画面と個別コメントの両方から、Copilot cloud agent に修正依頼を出せます。

### ユーザーにとって良いこと
外出先でもレビューコメントからすぐ修正作業を始められます。手動でプロンプトを書く手間が減り、PR の滞留を抑えやすくなります。

### アクションプラン
- モバイルでのレビュー対応を許容するチームは、GitHub Mobile の最新 production build を利用してください。
- PR レビュー運用に `Fix with Copilot` を組み込み、コメント修正の起点として周知してください。
- モバイル経由での修正依頼が増える場合は、承認・再レビューの流れを明文化してください。
