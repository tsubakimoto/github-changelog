## GitHub Code Quality license estimate in public preview

**URL:** https://github.blog/changelog/2026-07-13-github-code-quality-license-estimate-in-public-preview

### 要約
GitHub Code Quality の利用状況から、エンタープライズ単位で想定ライセンス費用を確認できるようになりました。パブリックプレビュー期間中は無料ですが、2026-07-20 の一般提供開始前に、導入後の請求インパクトを把握できます。

### ユーザーにとって良いこと
導入前にコスト感を見積もれるため、Code Quality を組織で継続利用するか判断しやすくなります。請求の見通しが立ち、想定外のコスト増を避けやすくなります。

### アクションプラン
- Billing and licensing の Licensing 画面を開き、Code Quality カードで消費ライセンスと月額見積もりを確認してください。
- 7 月 20 日の一般提供に向けて、active committer あたり月額 $10 の課金影響を事前に見積もってください。
- ⚠️ 見積もりには GitHub Actions の分や GitHub Copilot Autofix などの使用量課金は含まれないため、別途確認してください。

## Separate SSO and Organizations pages in Settings

**URL:** https://github.blog/changelog/2026-07-13-separate-sso-and-organizations-pages-in-settings

### 要約
ユーザー設定の「SSO & Organizations」ページが、SSO と Organizations の 2 つの独立したページに分かれました。関連設定を個別に見つけやすくなり、アカウント設定全体の操作性が改善されています。

### ユーザーにとって良いこと
SSO と組織設定を別々に管理できるため、必要な項目へより早くたどり着けます。設定画面の混在が減り、管理作業の迷いも少なくなります。

### アクションプラン
- ヘルプドキュメント、社内手順、スクリーンショット内の「SSO & Organizations」への案内を新しい分割後のページ名に更新してください。
- サポート用の案内文やブックマークが旧ページを指している場合は、SSO と Organizations の個別ページへ修正してください。
- この変更は自動適用なので、利用者側での有効化作業は不要です。
