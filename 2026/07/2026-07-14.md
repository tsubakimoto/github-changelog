## GitHub Copilot for JetBrains expands BYOK capabilities

**URL:** https://github.blog/changelog/2026-07-14-github-copilot-for-jetbrains-expands-byok-capabilities

### 要約
GitHub Copilot for JetBrains に、独自モデル接続やカスタマイズを広げる BYOK 機能が追加されました。カスタムエンドポイント、プラグイン管理、Claude agent provider のカスタマイズ、ローカルサンドボックス、Copilot CLI のデバッガー skill まで、IDE 内の調整幅が大きく広がっています。

### ユーザーにとって良いこと
チームのワークフローや利用モデルを JetBrains IDE 上でより細かく合わせ込めるようになります。設定画面や CLI を行き来せずに、Copilot を開発環境に寄せて運用しやすくなります。

### アクションプラン
- JetBrains 版 Copilot を使っている場合は、OpenAI-compatible な custom endpoint と API key の接続可否を確認してください。
- チーム標準のプラグインやカスタム agent を使うなら、Marketplace 経由の配布手順と customizations の設定手順を見直してください。
- public preview の項目（Claude agent provider、local sandboxing、Copilot CLI の debugger skill）を採用する場合は、利用対象と検証環境を分けて試してください。

## Code scanning shows AI security detections on pull requests

**URL:** https://github.blog/changelog/2026-07-14-code-scanning-shows-ai-security-detections-on-pull-requests

### 要約
Code scanning が、CodeQL ではカバーしきれない言語やフレームワークに対して AI ベースの検出を pull request 上で表示するようになりました。検出結果は PR に直接出るため、マージ前に追加の脆弱性候補を確認できます。

### ユーザーにとって良いこと
既存の CodeQL の外側にあるコードも、PR の流れの中で早めに確認できます。AI 由来の結果はラベル付きで区別でき、レビュー時に何を優先して見るべきか判断しやすくなります。

### アクションプラン
- Enterprise policy で AI security detections を許可し、必要な organization に対して有効化してください。
- 対象 repository では GitHub code security と CodeQL default setup を有効にしてください。
- ⚠️ この機能は informational で、PR の merge をブロックしません。運用上の gate にしたい場合は別のチェックを併用してください。

## Dependabot version updates introduce default package cooldown

**URL:** https://github.blog/changelog/2026-07-14-dependabot-version-updates-introduce-default-package-cooldown

### 要約
Dependabot の version updates は、既定で新しいリリース公開から 3 日待って PR を作成するようになりました。セキュリティ更新は遅延せず、既定の cooldown は supply chain リスクを少し落とすための変更です。

### ユーザーにとって良いこと
公開直後の壊れたリリースや不正なリリースを、そのまま取り込むリスクを下げられます。急がない依存更新に少し時間を置けるので、安定性を優先しやすくなります。

### アクションプラン
- `.github/dependabot.yml` を確認し、既定の 3 日 cooldown で問題ないかを判断してください。
- 必要に応じて cooldown 期間を変更するか、オプトアウト設定を明示してください。
- ⚠️ Security updates は即時のままなので、通常の version updates と運用を分けて扱ってください。

## Security reviews now available in the GitHub Copilot app

**URL:** https://github.blog/changelog/2026-07-14-security-reviews-now-available-in-the-github-copilot-app

### 要約
GitHub Copilot app で、作業中の変更に対して `/security-review` を実行できるようになりました。Copilot CLI にあった AI ベースのセキュリティレビューを、日常の coding workflow から直接呼び出せる public preview です。

### ユーザーにとって良いこと
コードを外に出す前に、注入系や XSS、パストラバーサルなどの高影響な問題を早めに見つけやすくなります。ローカル変更のまま再確認できるので、修正と再チェックの往復が短くなります。

### アクションプラン
- Copilot app で対象プロジェクトを開き、変更を加えたあとに `/security-review` を実行してください。
- レビュー結果が出たら、severity と confidence を見て優先度の高い指摘から修正してください。
- public preview のため、導入範囲を段階的に広げ、既存の code scanning・Dependabot・secret scanning と併用してください。
