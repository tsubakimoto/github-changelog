## Enterprises can default to auto model selection

**URL:** https://github.blog/changelog/2026-07-01-enterprises-can-default-to-auto-model-selection

### 要約
Enterprise 管理者が、`managed-settings.json` で Copilot のモデル選択を `auto` に設定できるようになりました。これにより、新しい会話は自動モデル選択を既定で開始できますが、ユーザーは会話ごとに別モデルへ切り替えられます。

### ユーザーにとって良いこと
企業全体でモデル選択の初期状態を揃えられるため、運用のばらつきを減らせます。Copilot の既定動作を統制しつつ、必要時の手動切り替えも維持できます。

### アクションプラン
- `.github-private/copilot/managed-settings.json` に `model: "auto"` を追加してください。
- Enterprise の AI Controls で設定が有効になっているか確認してください。
- この設定は新規会話にのみ効くため、既存の会話動作は別途周知してください。

### リファレンス
- [Enterprises can default to auto model selection](https://github.blog/changelog/2026-07-01-enterprises-can-default-to-auto-model-selection)

## GitHub Models is being fully retired on July 30, 2026

**URL:** https://github.blog/changelog/2026-07-01-github-models-is-being-fully-retired-on-july-30-2026

### 要約
GitHub Models は 2026-07-30 に完全終了し、playground、model catalog、inference API、BYOK も利用できなくなります。7/16 と 7/23 には短時間の brownout も予定されています。

### ユーザーにとって良いこと
移行期限と停止前の検証タイミングが明確になり、依存先の置き換え計画を立てやすくなります。事前に移行すれば、停止日以降の業務影響を避けられます。

### アクションプラン
- GitHub Models を使っているアプリ、ワークフロー、SDK 利用箇所を洗い出してください。
- 7/16 までに Azure AI Foundry など代替先へ移行し、7/23 の brownout 前に再検証してください。
- `github models` 前提のドキュメントや設定値を停止日までに更新してください。⚠️ 7/30 以降は関連機能が利用不可になります。

### リファレンス
- [GitHub Models is being fully retired on July 30, 2026](https://github.blog/changelog/2026-07-01-github-models-is-being-fully-retired-on-july-30-2026)

## Enterprise managed-settings.json is generally available

**URL:** https://github.blog/changelog/2026-07-01-enterprise-managed-settings-json-is-generally-available

### 要約
Enterprise managed-settings.json が GA になり、`.github-private` の `copilot/managed-settings.json` で AI 標準を管理できるようになりました。VS Code と Copilot CLI で、ユーザー側設定よりこのファイルが優先されます。

### ユーザーにとって良いこと
企業側で Copilot の利用方針を一元管理でき、クライアントごとの設定差を減らせます。更新はサーバー側で取得・キャッシュされるため、運用の再現性も高まります。

### アクションプラン
- 設定のホスト先となる組織を AI Controls で選択してください。
- `copilot/managed-settings.json` を `.github-private` リポジトリに配置し、必要なキーだけを追加してください。
- 既存の `settings.json` 互換パスを使っている場合は、今後の標準パスへ移行してください。

### リファレンス
- [Enterprise managed-settings.json is generally available](https://github.blog/changelog/2026-07-01-enterprise-managed-settings-json-is-generally-available)

## New C++ language server config skill for Copilot CLI

**URL:** https://github.blog/changelog/2026-07-01-new-c-language-server-config-skill-for-copilot-cli

### 要約
Copilot CLI に C++ Language Server 向けの新しいセットアップ skill が追加されました。`compile_commands.json` の生成・更新を自動化し、CMake や MSBuild の初期設定を簡単にします。

### ユーザーにとって良いこと
プロジェクトの解析精度が上がり、補完・診断・リファクタリングが実コンパイラの見方に近づきます。手作業でのビルド設定整備を減らせます。

### アクションプラン
- `copilot-plugins` から `cpp-language-server` をインストールしてください。
- プロジェクトで `regenerate compile commands` か `load project` を実行してください。
- 独自ビルドシステムがある場合は、同じ手順を再現できる project-specific skill を作成してください。

## Set AI credit session limits in Copilot CLI and SDK

**URL:** https://github.blog/changelog/2026-07-01-set-ai-credit-session-limits-in-copilot-cli-and-sdk

### 要約
Copilot CLI と SDK で、セッションごとの AI credit 上限を設定できるようになりました。インタラクティブでは `/limits`、非対話実行では `--max-ai-credits` を使って制御できます。

### ユーザーにとって良いこと
自動化や長時間ジョブのコスト上振れを抑えやすくなります。上限に達するとタスクを止めて通知するため、予算管理がしやすくなります。

### アクションプラン
- 非対話ジョブには `--max-ai-credits` を付けて実行上限を明示してください。
- インタラクティブ利用では `/limits` で上限を確認・調整してください。
- Copilot CLI 1.0.66 以上、SDK 1.0.5 以上へ更新してください。

### リファレンス
- [Set AI credit session limits in Copilot CLI and SDK](https://github.blog/changelog/2026-07-01-set-ai-credit-session-limits-in-copilot-cli-and-sdk)
