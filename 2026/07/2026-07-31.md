## Gemini 2.5 Pro and Gemini 3 Flash deprecated

**URL:** https://github.blog/changelog/2026-07-31-gemini-2-5-pro-and-gemini-3-flash-deprecated

### 要約
GitHub Copilot の全体験で Gemini 2.5 Pro と Gemini 3 Flash が非推奨になりました。代替はそれぞれ Gemini 3.1 Pro (Preview) と Gemini 3.6 Flash です。

### ユーザーにとって良いこと
利用中のモデルを把握していれば、Copilot の応答品質や可用性を維持しながら計画的に移行できます。

### アクションプラン
- ⚠️ Copilot Chat、inline edits、ask/agent モード、code completions で Gemini 2.5 Pro / Gemini 3 Flash を使っているワークフローを見直してください。
- 代替モデルとして Gemini 3.1 Pro (Preview) または Gemini 3.6 Flash へ切り替えてください。
- Copilot Enterprise 管理者は、Copilot 設定の model policy で代替モデルの利用を有効化してください。

- [Gemini 2.5 Pro and Gemini 3 Flash deprecated](https://github.blog/changelog/2026-07-31-gemini-2-5-pro-and-gemini-3-flash-deprecated)

## Enterprise teams model policy targeting in public preview

**URL:** https://github.blog/changelog/2026-07-31-enterprise-teams-model-policy-targeting-in-public-preview

### 要約
Enterprise teams 単位で Copilot のモデル利用を制御できる public preview が始まりました。Enterprise 全体のベースラインを保ちながら、特定チームに追加モデルを許可できます。

### ユーザーにとって良いこと
役割や成熟度に応じてモデルを段階的に開放でき、組織単位より細かい統制ができます。

### アクションプラン
- Enterprise の Copilot > Models で Enterprise teams mode を確認し、必要なら opt-in してください。
- 先に enterprise teams を作成し、Optional のモデルを割り当ててから本番適用に進めてください。
- 8 月 3 日以降に多くの顧客へ preview の opt-in が順次開放される前提で、モデルポリシーを見直してください。

## Restricting npm bypass-2FA granular access tokens

**URL:** https://github.blog/changelog/2026-07-31-restricting-npm-bypass-2fa-granular-access-tokens

### 要約
npm の 2FA バイパス設定付き granular access tokens が、トークン作成や権限変更などの機微な操作を実行できなくなりました。対象は npm GAT のみです。

### ユーザーにとって良いこと
漏えいしたトークンによるアカウント乗っ取りや権限昇格のリスクを下げられます。

### アクションプラン
- ⚠️ 2FA-bypass token で token 作成・削除、maintainer 変更、package access 変更などを行っている運用を停止してください。
- これらの操作は web または CLI から 2FA チャレンジ付きで実行してください。
- January 2027 に予定されている direct publish 制限に備え、trusted publishing (OIDC) または staged publishing へ移行してください。

### リファレンス
- [Restricting npm bypass-2FA granular access tokens](https://github.blog/changelog/2026-07-31-restricting-npm-bypass-2fa-granular-access-tokens)
