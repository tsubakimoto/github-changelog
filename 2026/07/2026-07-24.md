## Claude Opus 5 is now available in GitHub Copilot

**URL:** https://github.blog/changelog/2026-07-24-claude-opus-5-is-now-available-in-github-copilot

### 要約
Claude Opus 5 が GitHub Copilot で利用可能になりました。長時間・複数ステップのコーディング作業や、エージェント的なワークフローでのコード変更、回帰確認、ツール連携を含む作業に向けて最適化されています。

### ユーザーにとって良いこと
複雑な実装や検証を含むタスクで、より安定した推論と実行が期待できます。Copilot CLI や cloud agent など、複数の Copilot 面で同じモデルを選べるため、作業体験を揃えやすくなります。

### アクションプラン
- Copilot Pro+ / Max / Business / Enterprise のいずれかで利用可能か確認してください。
- Copilot Business / Enterprise の管理者は、Copilot settings で Claude Opus 5 の policy を有効化してください。
- rollout は段階的なので、モデルピッカーに出ない場合は少し待って再確認してください。
- ⚠️ Cyber/security-adjacent な要求は追加の安全制御でブロックされる場合があるため、必要なら benign な文脈を足すか別モデルを選んでください。
