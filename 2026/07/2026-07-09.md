## OpenAI’s GPT-5.6 Sol, Terra, and Luna are now available in GitHub Copilot

**URL:** https://github.blog/changelog/2026-07-09-openais-gpt-5-6-sol-terra-and-luna-are-now-available-in-github-copilot

### 要約
GitHub Copilot で OpenAI の GPT-5.6 系モデルが順次利用可能になります。Sol は高推論向け、Terra は汎用バランス型、Luna は軽量・低コスト向けで、用途に応じて選べます。利用には Copilot Business / Enterprise では管理者が policy を有効化する必要があり、ロールアウトは段階的です。

### ユーザーにとって良いこと
作業内容に応じて、精度・速度・コストのバランスを取りやすくなります。大規模コードベースの推論から軽い補助作業まで、同じ Copilot 環境で選択肢が広がります。

### アクションプラン
- Copilot Business / Enterprise の管理者は、Copilot settings で GPT-5.6 models の policy を有効化してください。これは **管理者が明示的にオンにする設定** です。
- チームで使う既定モデルを、Sol / Terra / Luna のどれにするか決めてください。
- Visual Studio Code、Copilot CLI、cloud agent など主要な利用先で、モデルピッカーに表示されるか順次確認してください。

## Organization-level targeting for GitHub Code Quality

**URL:** https://github.blog/changelog/2026-07-09-organization-level-targeting-for-github-code-quality

### 要約
Organization owners が、GitHub Code Quality の有効化・無効化を組織全体ではなく対象リポジトリ単位で行えるようになりました。カスタムプロパティ、手動選択、公開可視性、fork 状態で対象を絞れます。対象リポジトリには設定の固定もできます。public preview で、Enterprise Cloud と Team プランが対象です。

### ユーザーにとって良いこと
必要なリポジトリだけに Code Quality を適用でき、段階導入や例外運用がしやすくなります。管理者が設定を固定すれば、リポジトリ管理者による意図しない変更も防げます。

### アクションプラン
- Organization owners は、Code Quality を有効化するリポジトリ群を custom properties か manual selection で選定してください。これは **組織設定で対象範囲を絞る機能** です。
- 必須対象のリポジトリでは、repository administrators が変更できないよう enforce を有効にしてください。
- GitHub Enterprise Server では使えないため、対象環境が Enterprise Cloud / Team かを先に確認してください。

## Ask Copilot for a repository overview

**URL:** https://github.blog/changelog/2026-07-09-ask-copilot-for-a-repository-overview

### 要約
github.com 上で、初見のリポジトリに対して Copilot に高レベルの概要を求められるようになりました。Copilot はリポジトリの目的、使っている技術、貢献ガイドラインを要約します。README がない場合は、Copilot が README の生成にも使えます。

### ユーザーにとって良いこと
新しいリポジトリの理解にかかる時間を短縮できます。README が整っていないリポジトリでも、概要をつかみやすくなります。

### アクションプラン
- 新しいリポジトリに参加したメンバーへ、ホーム画面の Copilot 提案か Copilot Chat から overview を使う手順を案内してください。これは **全 Copilot プランで使える導入支援機能** です。
- README が欠けているリポジトリでは、Copilot 生成案をベースに README を整備してください。
- 貢献ガイドラインが Copilot の要約に反映されるよう、`CONTRIBUTING.md` や README の内容を更新してください。
