## CodeQL 2.26.3 improves GitHub Actions queries and JavaScript modeling

**URL:** https://github.blog/changelog/2026-08-19-codeql-2-26-3-improves-github-actions-queries-and-javascript-modeling

### 要約
CodeQL 2.26.3 がリリースされ、JavaScript / TypeScript / Vue のソースモデリングが強化されました。GitHub Actions 関連のクエリ精度も改善され、`merge_group` や `schedule` などの判定がより正確になります。

### ユーザーにとって良いこと
code scanning の検出精度が上がり、誤検知や見落としを減らしやすくなります。Vue や Sails などのアプリでも、実際のデータフローに沿った解析を使いやすくなります。

### アクションプラン
- GitHub code scanning の CodeQL バージョンを 2.26.3 に更新する。
- `codeql.actions.security.SelfHostedQuery` に依存するカスタムクエリがあれば、削除後の代替実装に移行する。
- `actions/output-clobbering/high`、`actions/cache-poisoning/*`、`actions/envvar-injection/critical` の結果差分を確認し、警告メッセージの変更をチームへ共有する。
- ⚠️ カスタム CodeQL クエリで古い GitHub Actions モデルを使っている場合は修正が必要。

## Track organization code quality trends

**URL:** https://github.blog/changelog/2026-08-19-track-organization-code-quality-trends

### 要約
Organization レベルの Code Quality ダッシュボードに Trends タブが追加されました。7 / 14 / 30 日の範囲で open findings の増減や、改善・悪化しているリポジトリを確認できます。

### ユーザーにとって良いこと
ポイントインタイムではなく時系列で品質を追えるため、改善の進捗や支援が必要なリポジトリを見つけやすくなります。チーム単位の品質改善を継続的に追跡できます。

### アクションプラン
- Code Quality を有効化している organization で Trends タブを確認する。
- 7 / 14 / 30 日の表示を切り替え、open findings の変化が大きいリポジトリを特定する。
- repository フィルタを使って、改善が進んでいるチームと支援が必要なチームを比較する。

## Multiple redirect URIs and token refresh for OAuth apps

**URL:** https://github.blog/changelog/2026-08-14-multiple-redirect-uris-and-token-refresh-for-oauth-apps

### 要約
OAuth app と GitHub App の認証まわりが強化されました。OAuth app は複数の redirect URI、短命 access token と refresh token、必要に応じた wildcard matching を使えるようになります。

### ユーザーにとって良いこと
アプリの認証構成をより柔軟かつ安全に設計できます。redirect URI の追加やトークン更新がしやすくなり、運用中の OAuth app の保守性も上がります。

### アクションプラン
- OAuth app で `offline_access` を使うか、短命 token / refresh token の採用方針を決める。
- 登録済み redirect URI を複数化し、必要な環境ごとに整理する。
- wildcard matching を有効化する場合は、ユーザー生成コンテンツを返すサイトでの悪用リスクを確認する。
