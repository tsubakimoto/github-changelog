1. GitHub Copilot 18 件
Improvement

Customize the reasoning level for Copilot cloud agent

8/3

Copilot cloud agent にタスクごとの推論レベル指定が追加されました。難しい問題では深く考えさせ、軽い処理ではトークン消費を抑えられます。対象は cloud agent を含む有料プランです。

Improvement

Enterprise team specialization for managed settings

8/3

Copilot の managed settings を、エンタープライズ全体ではなくチーム単位で上書きできるようになりました。`overridable` を付けたキーだけが差し替え可能で、`team-mappings.json` で複数チームへ割り当てられます。

Improvement

Trigger Copilot automations with comments

8/3

Issue / PR コメントをトリガーに Copilot cloud agent の自動化を起動できるようになりました。ドキュメント生成やエラー調査などを、レビューやトリアージの流れから自動化できます。

Retirement

Retiring the Copilot Billing Preview app

8/5

Copilot Billing Preview app が終了しました。Copilot の spend 管理は GitHub billing settings の AI usage ページに統合され、budget、cost center、usage pool もそこで扱います。

⚠️ Billing Preview app を使っていた場合は、AI usage ページへ運用を切り替えてください。

GA

Kimi K3 is now available in GitHub Copilot

8/6

Kimi K3 が GitHub Copilot で一般提供になり、VS Code、Copilot CLI、cloud agent、github.com などのモデルピッカーから選択できます。Business / Enterprise では既定で無効です。

⚠️ usage-based billing。open-weight model のため、セキュリティ・データガバナンス要件に照らして利用可否を判断してください。

Improvement

Copilot impact dashboard adds a return on investment section

8/7

Copilot impact dashboard に「Potential return on investment」セクションが追加されました。Copilot 利用コストと pull request 産出を並べ、導入段階ごとの価値を比較できます。

⚠️ 表示されるコストは推定値です。給与セレクターはモデリング入力であり、実給与データとして扱わないでください。

GA

Copilot code review effort levels are generally available

8/7

Copilot code review の Lite と Balanced が一般提供になりました。軽微な変更には速いレビュー、重要な変更には深いレビューを当てやすくなります。

⚠️ Low / Medium は Lite / Balanced に名称変更されていますが、既存設定は自動で引き継がれます。

Improvement

Copilot usage metrics API adds agent app activity

8/7

Copilot usage metrics API が、サードパーティの agent app 活動を agent ごとに集計して返すようになりました。enterprise、organization、user 単位の 1 日・28 日レポートで利用できます。

⚠️ 集計キーは agent 名ではなく agent_id を使ってください。データがない期間は新配列は返りません。

Secret scanning coverage updates

⚠️ 自動 Copilot review を継続したい場合は、対象ブランチの ruleset を手動で設定してください。

Improvement

License data quality improvements

⚠️ ライセンス監査に依存しているワークフローでは、レジストリ由来の判定に切り替わった前提で運用ルールを見直してください。

DeprecatedRetirement

Upcoming deprecation of GitHub Spark on github.com

8/5

GitHub Spark on github.com は新規ユーザー受付と新規アプリ作成を停止しました。既存ユーザーは 2026-08-31 までエクスポート可能で、`llm()` を使うアプリは別の inference provider へ置き換える必要があります。

Deprecated

Custom thread subscriptions are being deprecated

8/10

GitHub 通知の custom thread subscriptions が廃止されます。今後は thread-level の設定で Customize がなくなり、Subscribed と Not subscribed のみになります。

⚠️ 既存の custom 購読は Subscribed に自動変換されます。通知量が増える場合は個別スレッドの unsubscribe を案内してください。
