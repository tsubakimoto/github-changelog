GitHub Spark on github.com は新規ユーザー受付と新規アプリ作成を停止しました。既存ユーザーは 2026-08-31 までエクスポート可能で、`llm()` を使うアプリは別の inference provider へ置き換える必要があります。

⚠️ 既存の Spark アプリがある場合は 2026-08-31 までに repository へ書き出してください。

Deprecated

Custom thread subscriptions are being deprecated

8/10

GitHub 通知の custom thread subscriptions が廃止されます。今後は thread-level の設定で Customize がなくなり、Subscribed と Not subscribed のみになります。

⚠️ 既存の custom 購読は Subscribed に自動変換されます。通知量が増える場合は個別スレッドの unsubscribe を案内してください。
