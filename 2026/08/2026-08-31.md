## GitHub Copilot in VS Code, August 2026 releases

**URL:** https://github.blog/changelog/2026-08-31-github-copilot-in-vs-code-august-2026-releases

### 要約
VS Code の Copilot は、8 月のリリース群でエージェント作業の整理、長い会話の追跡、レビュー体験、ブラウザ連携、音声入力を大きく強化しました。Agents ウィンドウではチャットの並列表示や side conversation、セッション再接続、セッション詳細の確認がしやすくなっています。

### ユーザーにとって良いこと
会話やエージェントのやり取りが長くなっても、目的のプロンプトや変更履歴を追いやすくなります。レビュー、比較、ブラウズ、入力の各体験が統合されることで、VS Code 内で完結する作業が増え、コンテキスト切り替えを減らせます。

### アクションプラン
- VS Code 1.132 以降を使っているチームは、Agents ウィンドウでチャットの並列表示と prompt timeline を試し、長い作業を追いやすいレイアウトを標準化してください。
- `/btw` の side conversation や session continuation を使う運用が必要なら、どの種類の作業を分岐・継続対象にするかチームルールを決めてください。
- experimental な hybrid Markdown editor、chat sticky scroll、browser の element annotation、dictation の多言語対応は opt-in 機能なので、導入前に Insiders で検証してください。
- Agent Host を複数ウィンドウから使う場合は、同じセッションへ接続する運用と、共有してよいコンテキストの範囲を明確にしてください。
