## Multiple redirect URIs and token refresh for OAuth apps

**URL:** https://github.blog/changelog/2026-08-14-multiple-redirect-uris-and-token-refresh-for-oauth-apps

### 要約
OAuth app と GitHub App のリダイレクト設定が拡張され、OAuth app は最大 10 個の redirect URI を登録できるようになりました。あわせて、OAuth app は短命アクセストークンとリフレッシュトークンを opt-in で使えるようになり、必要に応じて wildcard matching も有効化できます。

### ユーザーにとって良いこと
複数環境や複数ドメインを持つアプリを、別アプリを作らずに運用しやすくなります。短命トークンの導入で、漏えい時のリスクを下げながら継続利用しやすい認証設計に移行できます。

### アクションプラン
- OAuth app の redirect URI 設定を見直し、開発・ステージング・本番の URL を必要数登録してください。
- `offline_access` スコープまたは常時短命トークン設定を使うか決め、SDK が refresh token フローに対応しているか確認してください。
- ⚠️ wildcard matching は便利ですが、ユーザー生成コンテンツを配信するサイトでは悪用される可能性があるため、必要な場合のみ有効化してください。

## Grok 4.6 is now available in GitHub Copilot

**URL:** https://github.blog/changelog/2026-08-14-grok-4-6-is-now-available-in-github-copilot

### 要約
Grok 4.6 が GitHub Copilot の新しい推論モデルとして提供開始され、エージェント型のコーディングや複数ステップのワークフローに向けて展開されます。Visual Studio Code、Copilot CLI、cloud agent など複数の製品で選択でき、課金は usage-based billing です。

### ユーザーにとって良いこと
長い推論やツール利用を伴う作業で、より強いモデルを選べるようになります。CLI やエディタ、cloud agent 間で同じモデルを使えるため、作業体験を揃えやすくなります。

### アクションプラン
- Copilot の model picker で Grok 4.6 を選べるか確認してください。
- Copilot Business / Enterprise の管理者は、Copilot settings で Grok 4.6 policy を有効化してください。
- usage-based billing の対象なので、利用頻度が高いチームは請求見積もりを確認してください。

## GitHub Copilot weekly releases — August 10

**URL:** https://github.blog/changelog/2026-08-13-github-copilot-weekly-releases-august-10

### 要約
Copilot の各製品にまたがる週次更新で、新しいモデル、Agent Plugins 1.0、より扱いやすいプラグイン管理、サイドチャットなどがまとめて紹介されています。Copilot CLI では `/tasks`、キューイング、`--plan` と `--mode autopilot` の併用、`/rewind`、`/app` のコンテキスト維持が追加されました。

### ユーザーにとって良いこと
エディタ、CLI、アプリ間でエージェント作業の連続性が増し、同じコンテキストで作業しやすくなります。プラグインやモデルの選択肢が増えることで、用途に合わせた Copilot の使い分けがしやすくなります。

### アクションプラン
- Copilot CLI を使っているチームは `/tasks` とキューイングを試し、実行中のエージェント運用を整理してください。
- Agent Plugins を使う場合は、VS Code / Copilot CLI / SDK / app の対応状況を確認して共通化を進めてください。
- `/rewind` に依存した復元運用が必要な場合は、既存の git ベース手順との差分を整理してください。
