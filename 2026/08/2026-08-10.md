## Copilot on web expands conversation controls

**URL:** https://github.blog/changelog/2026-08-10-copilot-on-web-expands-conversation-controls

### 要約
GitHub.com 上の Copilot Chat に、会話の最小化、最近の会話へのアクセス改善、トークン消費の可視化が追加されました。会話を中断しても戻りやすくなり、利用量も確認しやすくなっています。

### ユーザーにとって良いこと
ブラウザで作業しながら Copilot の返答を待てるため、チャット体験が途切れにくくなります。トークン使用量が見えるので、利用上限やコスト感の把握もしやすくなります。

### アクションプラン
- Copilot Chat を github.com で使っているチームは、新しい最小化/再開操作を案内してください。
- トークン表示を確認し、セッションごとの利用目安を運用ルールに反映してください。
- この変更は **一般提供** で、Copilot プラン利用者全体に適用されます。

## GitHub billing in India now supports automatic recurring payments

**URL:** https://github.blog/changelog/2026-08-10-github-billing-in-india-now-supports-automatic-recurring-payments

### 要約
インドの顧客向けに、適格な保存済みクレジットカードで月額・年額の自動継続課金ができるようになりました。RBI 要件に沿った payment mandate を使い、毎回の手動支払いを減らします。

### ユーザーにとって良いこと
支払いの手間が減り、請求失敗や更新忘れのリスクを下げられます。支払い方法の保存・削除フローは変わらないため、管理面の影響は小さめです。

### アクションプラン
- インドの請求先を持つ組織は、保存済みカードが自動更新に使えるか確認してください。
- 請求担当は、RBI の支払い委任要件に基づく自動課金の案内を確認してください。
- この変更は **対象地域のみ有効** で、インドの有料 GitHub プロダクト利用者に適用されます。

## Custom thread subscriptions are being deprecated

**URL:** https://github.blog/changelog/2026-08-10-custom-thread-subscriptions-are-being-deprecated

### 要約
GitHub 通知の custom thread subscriptions が廃止されます。今後は thread-level の設定で Customize がなくなり、Subscribed と Not subscribed のみになります。

### ユーザーにとって良いこと
通知設定がシンプルになり、購読状態の理解と管理がしやすくなります。新しい設定体系に統一されるため、挙動の予測もしやすくなります。

### アクションプラン
- custom thread subscriptions に依存しているチームは、Subscribed / Not subscribed 前提へ運用を見直してください。
- 既存の custom 購読は **Subscribed に自動変換** されるため、通知量の増加に備えて受信設定を点検してください。
- ⚠️ 細かな購読制御は廃止されるので、ノイズが増える場合は個別スレッドの unsubscribe を案内してください。
