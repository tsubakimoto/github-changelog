## Better tools for managing blocked users

**URL:** https://github.blog/changelog/2026-08-21-better-tools-for-managing-blocked-users

### 要約
ブロック済みユーザーの管理画面が、個人アカウントと組織向けに改善されました。ユーザー名・氏名・メールでの検索、長い一覧のソートとページ送り、ブロック理由での絞り込みができるようになっています。

### ユーザーにとって良いこと
モデレーション対象の確認や見直しが速くなり、誤操作も減ります。組織では、誰がブロックしたかや期限などの管理情報も追いやすくなります。

### アクションプラン
- 個人アカウント/組織の **Settings → Moderation → Blocked users** を開き、新しい検索・フィルタ・並び替えを確認する。
- 組織運用では、ブロック理由と private notes の記入ルールを決めて、モデレーション履歴を標準化する。
- 既存のブロック一覧が長い場合は、ページング前提で定期レビュー手順に組み込む。

## The new GitHub Copilot experience in Slack

**URL:** https://github.blog/changelog/2026-08-21-the-new-github-copilot-experience-in-slack

### 要約
GitHub の Slack 連携に、Copilot CLI と GitHub Copilot app のエージェント機能が public preview で追加されました。Slack の DM/チャンネル/スレッドから @GitHub を呼び出し、質問対応、Issue 操作、調査、実装、PR 作成までつなげられます。

### ユーザーにとって良いこと
会話の流れのまま作業を引き渡せるため、タスクの着手と進行が速くなります。非同期で進むので、会議中でも待ち時間なく進捗を受け取れます。

### アクションプラン
- 組織で **Copilot cloud agent policy** を有効化し、Slack の GitHub app をインストール/更新する。
- チームの Slack 運用に @GitHub を使った依頼テンプレートを追加し、Issue 作成・調査・PR 起票の役割分担を決める。
- ⚠️ public preview のため、運用開始時は PR に追加承認を必須にして、人の確認を通してからマージする。
- 使い始める前に、GitHub アカウント連携と利用可能なコマンドを共有する。

## Shared agentic work with GitHub Copilot in Microsoft Teams

**URL:** https://github.blog/changelog/2026-08-21-shared-agentic-work-with-github-copilot-in-microsoft-teams

### 要約
Microsoft Teams でも、@GitHub を使って共有可能な Copilot cloud agent セッションを開始できるようになりました。会話参加者が一緒に質問、計画、調整を行え、変更権限のある人は Copilot に実作業を進めさせられます。

### ユーザーにとって良いこと
会議の決定事項をその場で実作業に変えやすくなります。進捗や成果物を Teams のスレッドから追えて、後でターミナルや IDE に引き継げます。

### アクションプラン
- Teams 用 GitHub app を導入し、組織で **Copilot cloud agent** と **cloud sandboxes** のポリシーを有効化する。
- 公開チャンネル向けに既定リポジトリを設定し、DM/チャンネルごとの依頼ルールを整える。
- ⚠️ public preview のため、Copilot 作成 PR に追加承認を要求する設定を検討する。
- チームに @GitHub help の使い方を共有し、会議中のタスク移譲フローを定着させる。
