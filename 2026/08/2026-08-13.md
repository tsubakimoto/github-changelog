## License data quality improvements

**URL:** https://github.blog/changelog/2026-08-13-license-data-quality-improvements

### 要約
GitHub の dependency graph で、ライセンス判定の प्राथमिक source をパッケージレジストリのメタデータに切り替え、ClearlyDefined はフォールバックとして残します。これにより、依存関係のライセンス情報の欠落が大きく減り、SBOM や dependency review の精度が向上します。

### ユーザーにとって良いこと
依存関係のライセンス確認がより正確になり、監査やコンプライアンス対応の判断材料が増えます。新しいバージョンでもライセンス情報が入りやすくなるため、手動確認の手間が減ります。

### アクションプラン
- 依存関係レビューや SBOM を使っているチームは、ライセンス検出結果を再確認してください。
- ⚠️ ライセンス監査に依存しているワークフローでは、レジストリ由来の判定に切り替わった前提で運用ルールを見直してください。
- GitHub Advanced Security の license compliance を使う場合は、主要な依存パッケージで検出結果が変わっていないか確認してください。

## Block users from comments in personal repositories

**URL:** https://github.blog/changelog/2026-08-13-block-users-from-comments-in-personal-repositories

### 要約
個人所有リポジトリの pull request や issue のコメントから、ユーザーを直接 block / unblock できるようになりました。コメントの More メニューからそのまま操作でき、必要なら private note も付けられます。

### ユーザーにとって良いこと
スパムや迷惑行為への対応が速くなり、コメント画面から離れずにモデレーションできます。個人リポジトリの管理負荷を下げ、対応の一貫性も保ちやすくなります。

### アクションプラン
- 個人リポジトリの保守担当者は、コメント欄の More メニューから block / unblock 操作を確認してください。
- スパム対応手順がある場合は、コメント内での即時ブロックを前提に手順を更新してください。
- 必要に応じて、ブロック理由を残す private note の運用ルールを決めてください。

### リファレンス
- [Block users from comments in personal repositories](https://github.blog/changelog/2026-08-13-block-users-from-comments-in-personal-repositories)

## Gemini 3.7 Flash is now available in GitHub Copilot

**URL:** https://github.blog/changelog/2026-08-13-gemini-3-7-flash-is-now-available-in-github-copilot

### 要約
GitHub Copilot に Gemini 3.7 Flash が段階的に追加されます。Web/app 開発、agentic coding、コード品質、研究、検証の各面で改善があり、Copilot CLI を含む複数のクライアントで選択できます。

### ユーザーにとって良いこと
Copilot のモデル選択肢が増え、用途に応じてより良い応答や実装支援を選べます。複雑なコーディング作業や検証での精度向上が期待できます。

### アクションプラン
- Copilot Business / Enterprise 管理者は、組織で利用するなら Gemini 3.7 Flash Preview policy を有効化してください。
- Copilot Pro / Pro+ / Max / Business / Enterprise 利用者は、モデルピッカーで Gemini 3.7 Flash を選択して試してください。
- ⚠️ 料金は usage-based billing で provider list pricing です。利用量の多いチームは請求見積もりを確認してください。
