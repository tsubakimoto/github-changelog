## GitHub Copilot in Visual Studio — August update

**URL:** https://github.blog/changelog/2026-08-28-github-copilot-in-visual-studio-august-update-2

### 要約
Visual Studio の Copilot が、モデルの思考量や使用モデルをより細かく制御できるようになりました。あわせて、組織が公開した custom agents の検出、Copilot 利用状況の確認、Git agent による変更レビューも追加されています。

### ユーザーにとって良いこと
タスクの難易度に応じて reasoning を調整できるため、速度と精度のバランスを取りやすくなります。組織で配布した specialized agents やレビュー機能も使えるので、個人の工夫に頼らない開発フローを作りやすくなります。

### アクションプラン
- Visual Studio Insiders で thinking effort の Low / Medium / High を試し、チームの標準設定を決めてください。
- 組織で custom agents を配布する場合は、Visual Studio から見えることを前提に agent 名と説明を整備してください。
- PR 前のレビューに Git agent を使う運用を検討し、どの種類の変更を自動レビュー対象にするか決めてください。

## GitHub Copilot weekly releases — August 24

**URL:** https://github.blog/changelog/2026-08-28-github-copilot-weekly-releases-august-24

### 要約
Copilot の各製品で、セッション継続、管理機能、カスタマイズ、性能改善がまとまって展開されました。Slack / Teams、Copilot app、CLI、JetBrains、VS Code、Visual Studio にまたがって更新があり、チーム利用と個人利用の両面が強化されています。

### ユーザーにとって良いこと
会話や作業を複数の製品間で引き継ぎやすくなり、途中で中断しても作業を戻しやすくなります。管理者は plugins、MCP servers、skills、permission modes をより一貫して扱えるため、組織標準のワークフローを広げやすくなります。

### アクションプラン
- Copilot CLI を使っている場合は、`/plugin`、`/mcp`、`/skills` の新しい管理体験を確認してください。
- セッション継続が必要なチームでは、Slack / Teams からの shared agent sessions を使う運用ルールを決めてください。
- VS Code や Visual Studio を使うチームは、継続セッションや model comparison、single-pane Agents layout の導入可否を確認してください。

## Upcoming changes to GitHub Copilot policies and billing

**URL:** https://github.blog/changelog/2026-08-28-upcoming-changes-to-github-copilot-policies-and-billing

### 要約
Copilot Business / Enterprise の課金とポリシーに、複数の変更が予定されています。2026-10-01 から seat の前払い課金が始まり、2026-09-28 以降は Copilot Chat on github.com、GitHub Mobile、cloud agent が統合された単一体験へ移行し、Copilot code review の Default は Balanced に変わります。

### ユーザーにとって良いこと
課金ルールと体験ポリシーが整理されるため、組織側での管理がしやすくなります。code review の既定が Balanced になることで、より深いレビューをデフォルトにした運用へ寄せやすくなります。

### アクションプラン
- ⚠️ 2026-09-28 までに、Copilot Chat / Mobile / cloud agent の unified experience を opt-out するかどうかを管理者が決めてください。
- ⚠️ 2026-09-28 までに、Copilot code review の Default を Lite のまま維持する必要がある組織・リポジトリは、明示的に Lite を選択してください。
- ⚠️ 2026-10-01 までに、Copilot Business / Enterprise の seat 課金、前払い、追加利用料、請求方法の影響を財務・管理者で確認してください。
- seat の追加や削除に伴う請求タイミングを、社内の購買・運用フローに反映してください。
