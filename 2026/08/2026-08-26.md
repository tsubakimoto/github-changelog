## Global model policy generally available

**URL:** https://github.blog/changelog/2026-08-26-global-model-policy-generally-available

### 要約
Copilot の一般提供モデルに対する既定のモデルポリシーが、企業向けに段階的に有効化されます。未設定のモデルは既定ポリシーに従う形になり、管理者はモデルごとに永続的な設定も可能です。

### ユーザーにとって良いこと
モデルの有効/無効が企業の既定ポリシーにそろうため、管理運用がしやすくなります。個別の明示設定は保持されるので、意図した制御を崩さずに標準化できます。

### アクションプラン
- 企業の Copilot モデル設定で、未設定モデルがどの状態になるか確認してください。
- 1 つずつ明示設定しているモデルがあれば、そのまま維持される前提で見直してください。
- 2026-09-01 まで段階的に反映されるため、組織内の適用状況を確認してください。

## GitHub Apps can now access enterprise billing data

**URL:** https://github.blog/changelog/2026-08-26-github-apps-can-now-access-enterprise-billing-data

### 要約
GitHub App に enterprise billing 権限を付与し、企業の請求データへアクセスできるようになります。read / read and write の2段階があり、個人トークンに依存していた請求自動化をアプリ化できます。

### ユーザーにとって良いこと
請求・利用状況・予算管理の自動化を、個人に紐づかない安定した認証方式で運用できます。API の利用も高いレート制限で扱えるため、財務・BI 連携に向いています。

### アクションプラン
- 請求データ連携を PAT で行っている場合は、GitHub App への移行を検討してください。
- enterprise billing 権限を必要最小限の read / read and write で設定してください。
- この権限は GitHub Enterprise Cloud で利用可能なため、対象環境を確認してください。
